## What I built (matches your spec)

- **`grow_local_<ref>`** arms (`anchor`/`decoy`/`oracle`), no router, no replay, single dense. Same
  scaffold-distill loss + anchor/base-hop KL as `naive`, **plus** a locality penalty on the **newly
  appended blocks' residual forward footprint**:
  `local = mean_over_new_layers mean_batch ‖Δh_last‖² / (‖h_in_last‖² + 1e-6)` on the reference batch,
  added as `λ·local` (`BK_LOCAL_LAMBDA`, default 1.0). Computed via forward hooks on `layers[-GROW:]`.
- **ref distributions:** `anchor` = anchor-text + base-hop only; `decoy` = + same-template **unlabeled**
  prompts built from **unused** subjects (not in any stream, no labels, not future facts); `oracle` = +
  actual prior-stream prompts (**INVALID upper bound**, uses old data).
- **Diagnostics per round** (eval-only): `delta_new` (new-block Δ on current stream), `delta_anchor`,
  `delta_decoy`, `delta_old` (on prior-stream prompts) — the decisive test is whether `delta_old` falls
  vs `naive` and tracks retention.
- **Controls:** `BK_LOCAL_NOGROW=1` → fixed-capacity variant (grow once, reuse, same locality loss).
  Large-from-start I'll add as a separate config if the first result is promising.

## Two things I want your read on

1. **λ and the plasticity/locality tension.** The penalty drives new-block Δ→0 on the reference, but the
   scaffold loss needs Δ high on new-stream keys. λ=1.0 is a guess. Smoke will show whether new facts
   still learn (delta_new high, newest recall OK) while delta_anchor/decoy fall. If λ has to be tiny to
   keep plasticity, locality won't reach old prompts and it degenerates to naive; if λ too big, newest
   collapses. Do you want a small λ sweep {0.3,1,3} in the pilot, or fix λ=1 first and only sweep if the
   signal is borderline? I lean fix-λ=1, sweep only if borderline.
2. **The decisive read.** If `delta_old` stays ≈ `naive`'s while `delta_anchor`→0, that's your predicted
   template-inseparability failure (localized on the wrong distribution). `decoy` is the test of whether
   same-template unlabeled coverage fixes it. If `oracle` (old-prompt penalty) also fails to cut
