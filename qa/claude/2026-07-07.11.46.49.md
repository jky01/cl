# R39 design round: rehearsal-free answer-function protection — and a reframing our own result forces

Capstone reframed + pushed (d8a7806, `docs/CAPSTONE.md`). Footprint thread closed. This is the design round
for R39. I want to reason through the frontier with you, not hand you a spec — I think R38B-A changes what
the right target even is.

## The reframing I want to argue

We've been framing R39 as "rehearsal-free protection of independent new facts." But stack our own results:

- R36-A / R38B: to retain an independent fact you must replay it; no neighbor spillover. Item-level.
- R36-C: protecting old realized update *directions* ≠ protecting the answer *function*; first-order failed.
- R38B-A: the ONLY thing that retained with zero replay was knowledge **already anchored in the prior**;
  independent invented facts collapsed to ~0.17 under the identical gentle objective.

Put together, I think these point at an information-theoretic wall: **to protect fact A's answer function
using NO A-specific information, you must either (a) protect the entire function everywhere — impossible at
finite capacity while still writing B — or (b) reconstruct A from the model itself (generative replay),
which requires the model to *index its own knowledge* without a prompt.** For arbitrary independent facts,
(b) is itself unsolved: a 0.5B model can't enumerate "which subjects/relations did I learn" to self-quiz
them. So rehearsal-free retention of *truly independent* facts may be close to impossible in principle — not
an engineering gap.

If that's right, the honest frontier is NOT "protect independent facts without rehearsal." It's the flip
side of R38B-A: **engineer prior-anchoring for NEW facts so they inherit the no-replay retention floor.**
I.e., stop treating new facts as independent tuples to be defended, and instead write them in a form that
overlaps existing model structure, so later writes do less destructive work on them — exactly what real
facts get for free. That's the mechanism our own data most directly motivates, and I don't think we've named
it before.

## Four candidate mechanisms, and where I'd bet

Regime (agreed): independent synthetic / KG-shaped facts in `s2/lifecycle_bakeoff.py` (real text would mask
failure). Reference arms: naive/no-replay, best `nswrite`, compact-replay, gold-old oracle.

1. **Generic-probe functional anchor** — KL to M_{t-1} on a fixed broad NON-old probe set. Pure
   training-state constraint, unambiguously rehearsal-free. My bet: fails to cover specific old facts'
   directions (the R38 neutral anchor already hurt, though that anchored to base). Useful as the honest
   "functional constraint without old data" floor, not the answer.

2. **Generative self-replay** — M_{t-1} samples its own (question, answer) to rehearse; no stored old data.
   Canonical rehearsal-free. But the **self-indexing problem**: to replay fact A the model must first
   *produce* A's question unprompted. For templated facts it must enumerate learned (subject, relation)
   pairs — which it has no handle on. I suspect this degrades to "replay whatever the model most confidently
   emits," which is a biased, low-coverage sample → partial retention at best. Worth measuring *how* biased.

3. **Realized-ΔΘ null-space write** — project new updates off the running low-rank basis of past ΔΘ
   (training-state, no old items). Rehearsal-free by the strict line, but R36-C's direction≠function caveat
   says it likely underperforms. Include as an ablation, don't expect it to win.

4. **Anchored write (the one I'd actually build)** — when writing new fact B, first map it onto existing
   structure so it is NOT independent. Concrete operationalizations I'm weighing:
   - **Bridge distillation**: generate a short self-consistent "explanation" linking B to concepts the base
     already represents (e.g., relate the new entity to known categories), and train on B + bridge jointly,
     so B's representation reuses prior-anchored directions.
   - **Nearest-schema init**: before gradient writing B, find the activation-space neighbor among known
     concepts and initialize B's write in that subspace (write a delta from the anchor, not from scratch).
   - **Key-tied consolidation**: force B's answer to be retrievable through a stable pretrained representation
     of its subject (anchor the subject encoding, only learn the association) — reduces the write to the
     minimal new bits, which R38B-A suggests is what survives.

## The measurement that decides it

The clean test of the reframing: take independent synthetic facts, apply an anchoring mechanism (4), and
measure **zero-replay old-para retention**. If anchoring lifts synth zero-replay from ~0.17 toward the
real-text 0.63 floor, we've *manufactured* the prior-anchoring effect — that would be a genuine rehearsal-free
retention result for new knowledge, and arguably the first real crack in the wall. If it doesn't move, the
wall is real and the honest capstone line is "cheap retention requires either rehearsal or pre-existing
anchoring, and you can't fake the latter."
