## The win, and its honest scope

**With the recurrence expressed as a local step (interleaved I/O) AND attention restricted to a local
window, csum_reset length-extrapolates from [3,12] to L40 at 0.95** — the model executes the state
update step-by-step, so length is emergent, not a template. This is exactly the "execute vs emit"
formulation the whole framing pointed at. Both ingredients are load-bearing: full-attention interleaving
alone only reaches L16 (the model still exploits length-dependent global features); the local window
forces the position-invariant local transition.

Honest scope, per your caution:
- **Supplied, not discovered.** The interleaved format supplies the step decomposition and the local
  window supplies the locality; the model learns to EXECUTE the transition. Legitimate forward-
  extrapolation capability, not autonomous discovery of the algorithm.
- **Inference cost.** It uses a growing generated trace (interleaved output) — satisfies "no external
  retrieval / no episodic memory," but it is NOT constant-compute / strong-memory-free; the trace is
  the working memory. Disclosed.
- **Consistent with the toy line.** Extrapolation is representation/architecture-dependent (parity
  needed binary, quadratic needed a constrained class, and here the recurrence needed a local-step
  format + local attention). It does not happen automatically from "learning the rule."

## Where this leaves the whole session, and the honest answer to the user's question

The user asked: can ONE model learn several rules and self-derive/continue them beyond training? The
scrupulous answer we can now support:
- RETAIN multiple rules in one model: yes (toy consolidate; no catastrophic forgetting).
- ACQUIRE a rule as a genuine in-weights algorithm: yes, IF sufficient equivalence-breaking
  (multi-environment) evidence (gate 2: csum_reset recurrence, reset-distance-general + counterfactual).
- EXTRAPOLATE forward (continue beyond training length): yes, IF the rule is expressed as a locally-
  executable step with locality enforced (this result) — NOT automatically, and NOT via autonomous
  discovery.
- AUTONOMOUSLY discover an extrapolating rule from raw input with no such structure: NO (the discovery
  toy: even with x·x reachable, GD picks a non-extrapolating local fit; identifiability needs
  environment structure).

So the load-bearing thesis stands and is now anchored in a real transformer: **the hard parts are
identifiability (needs equivalence-breaking evidence) and executable form (needs a local-step
representation); retention is comparatively easy.** Curriculum/representation/architecture are
first-class, not incidental.
