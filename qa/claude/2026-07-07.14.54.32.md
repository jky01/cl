## Organizing frame: decompose the cost, because each field attacks a DIFFERENT term

Independent facts have irreducible per-item information (R38B-A lower bound; no mechanism beats it). But total
cost decomposes into four terms, and we've only touched two:

```
total = (#patterns × bits/pattern)        ← schema extraction (already queued: schema_comp)
      + (#exceptions × bits/exception)     ← untouched
      + interference write-cost            ← nswrite touches it, but SATURATES (occ 0.74→0.91)
      + recompression amortization cost    ← untouched; replay pays full O(N) every write
```

Claim: keytie (R39-A) failed because it moved "where the retrieval key points," which is in NONE of these
terms. Each idea below is tagged with the term it attacks.

## The six ideas (each: source field → mechanism → why it's a different corner than what failed → harness test)

### 1. Vector-Symbolic Architecture / superposition storage (VSA + Modern Hopfield) — attacks bits/fact + the interference SUBSTRATE
Source: Holographic Reduced Representations (Plate), VSA, Modern Hopfield (Ramsauer et al = attention).
Store facts as bound `key ⊗ value`, superposed in one vector. Adding fact N+1 costs analyzable noise growing
~√(N/dim), not localized-subspace contention. Why genuinely different: nswrite protects a LOCALIZED write
subspace, so it saturates; VSA has no single subspace to fill — capacity degrades gracefully, not a wall.
It's a different answer to interference. Test: an MLP key-value superposition layer, write facts VSA-style,
measure interference-vs-#facts curve against localized writing (VSA predicts √ growth vs linear collapse).
Risk: may need architectural change to the dense MLP; unbinding precision drops at high load. This is the one
that swaps the STORAGE SUBSTRATE — every negative we have (keytie, EWC, OGD, R36-C) was on the same localized
substrate.

### 2. Dentate-gyrus targeted pattern-separation growth — attacks interference write-cost AT saturation
Source: hippocampal neurogenesis specifically recruits new neurons for PATTERN SEPARATION of similar new
memories (reduce interference), not generic capacity. Gives growth a precise trigger + job: WHEN nswrite
subspace saturates, grow a few units whose ONLY loss is to orthogonalize the new fact from the old facts
colliding with it in write-space, then distill back to dense. Why it matters: our growth is always negative
because we grow generic capacity; biology grows only at the interference bottleneck and only to separate.
This turns the phase-2 "what to grow on saturation" into a testable hypothesis and is the lowest-risk direct
extension of nswrite. Test: nswrite occupancy crosses threshold → grow k units with an orthogonality loss vs
nearest colliding old fact → distill to dense; does post-saturation retention un-freeze?

### 3. LSM-tree multi-timescale weight tiers (amortized compaction) — attacks recompression amortization
Source: databases' Log-Structured Merge tree / leveled compaction. Replay currently repays O(N) every write.
LSM insight: tier + amortize — new writes hit a fast buffer, periodically merge level-by-level into denser
slower tiers, so any fact is recompressed O(log N) times, not O(N). Why it matters: this makes consolidation
SUBLINEAR WITHOUT schema, and it's orthogonal to schema (stack them → O(patterns) × log amortization). Maps
to multi-timescale biological consolidation (fast synaptic → slow → systems). Test: three weight tiers (fast
LoRA buffer / mid / dense), compaction at different stream frequencies, measure replay-touches-per-fact
falling from O(N) toward O(log N) with retention held.

### 4. Recombinant generative self-replay (sharp-wave ripples) + coverage sketch — attacks the self-indexing wall
Source: sleep replay is COMPRESSED, ~20x accelerated, and REORDERED/RECOMBINED — not veridical playback.
Self-replay's blocker is "no index of own codebook." Biology's answer isn't addressing exact old items; it's
SAMPLING recombined sequences from the schema distribution + a cheap Bloom-filter-style coverage sketch to
find under-probed regions. Why it matters: it sidesteps self-indexing (probe the manifold, don't call the
item), and recombination is precisely the answer to your earlier worry about biased "replay only the easy
items." Test: on schema_comp, an arm that consolidates NOT by replaying items but by sampling recombined
A→C probes with coverage-sketch guidance, vs item-replay.

### 5. Complementary Learning Systems ratio → retarget the goal to O(patterns) + O(exceptions)
Source: the half of CLS usually dropped — neocortex consolidates only regularities CONSISTENT across many
episodes; contradictory/one-off stays episodic. This REDEFINES the target: weights store only schema-
consistent regularities; genuinely idiosyncratic facts live as a small O(#exceptions) residual that alone
earns expensive per-item replay. If most of "hundreds of books" is schema-covered, exceptions are few → the
whole thing is highly sublinear. We've been assuming we must retain EVERY independent fact (R38B-A says that's
impossible); maybe the right target is "regularities + few exceptions," not O(1). An honest dimensionality
reduction. (Constraint check: exceptions must still be in-weights, no inference memory — they'd be
consolidated but flagged for higher replay budget.)

### 6. Renormalization group / Kolmogorov structure function — the theory for WHAT schema_comp should keep
Source: physics RG coarse-graining + algorithmic information theory's structure function (split a string into
STRUCTURE vs NOISE). Treat each consolidation as an RG coarse-graining step: integrate out item-specific
detail, keep relevant effective schema parameters. The structure function gives a principled cut between
"structure (compress into a rule)" and "incompressible noise (store as exception)" — feeding idea 5's
patterns/exceptions decision and giving schema_comp's metric a theoretical basis instead of a hand-set
threshold.

## My ranking (want you to contest it)

Attacks the wall AND testable AND non-overlapping with the queued schema_comp:
1. VSA/superposition — boldest, a genuinely NEW corner for interference (distributed √ decay vs nswrite
