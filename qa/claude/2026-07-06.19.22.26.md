# R37-A plan — but first: `naive` ALREADY IS frozen growth-isolation, and it forgets. So the novel lever is a LOCALIZED write, not isolation-by-freezing.

## The reframe: our `naive` baseline is already grow-and-isolate-frozen

In `s2/lifecycle_bakeoff.py` `run_consolidate`, **every** arm (including `naive`) does, each round:
`grow_qwen(dense, GROW)` (append identity-init layers) → `set_trainable_top(dense, GROW)` (freeze
everything, unfreeze only the newest GROW layers) → train on the new stream. So `naive` = **grow +GROW
layers/round, train only the newest block, freeze all prior blocks, all layers always-active (no router),
NO replay.** That is *exactly* "frozen growth isolation." And it forgets **+0.762** (R36-A2 table).

So the crude R37-A hypothesis ("give each stream its own frozen block ⇒ retention without replay") is
**already refuted by the `naive` arm.** I almost proposed re-running it as a new arm; it would reproduce
naive.

## Why frozen isolation fails — the READ/WRITE asymmetry

You can freeze *where you write* (old blocks), but in a sequential dense model **every layer READS every
prompt.** A stream-0 fact lives in frozen layers ~24–25, but at final eval its prompt still flows through
layers 26–35 (trained on streams 1–5), which **add** to its residual stream and corrupt the answer. So
freezing the write does not isolate the read. The only two escapes are:
1. **Route** old prompts around new blocks → needs task ID / learned router / key bank → violates
   no-inference-memory, and the router itself is a CL problem (forgets). You already flagged this. Invalid.
2. **Make each new block output ≈ 0 on old prompts** (so it doesn't perturb them) — *without* using old
   data.

## The genuinely-novel lever: LOCALIZED / minimal-footprint WRITE (no replay, no router, all-active)

grow_qwen inits each new block to **exact identity** (o_proj & down_proj zeroed → block output = 0
everywhere). Training on the new stream makes it non-zero — but there is currently **no constraint keeping
it ≈0 on inputs it doesn't need to change.** Proposal: train each new block with a **locality / minimal-
perturbation prior** — penalize the block's output magnitude on a broad reference (anchor + base-hop +
optionally the model's own prior activations) so it fires **only on the new-stream keys** and stays ≈0
elsewhere. If a new block is ≈0 on old-stream prompts, it cannot perturb them → **retention without replay,
without a router, single un-routed dense checkpoint.**

This is different from everything in R19–R36: not projection (R36-I/C protect the *gradient*; this
constrains the *forward output footprint*), not replay (no old data), not routing. It directly attacks the
READ-interference that dooms frozen isolation. It connects to the old s0 "locality" idea but in the
grow-and-consolidate frame.

**Proposed arms (all no-router, single dense, no replay; `naive` = the frozen-isolation floor we already
have):**
- `grow_local_out`: new-block output L2 penalty on anchor+base-hop batches (`λ·‖block_out‖²`), driving
  minimal footprint; new facts still learned via the scaffold-distill loss.
- `grow_local_gate`: a learned scalar gate `g(h)=σ(w·h+b)` per new block, anchored to **0 on
  anchor/base-hop** and free on new-stream (contrastive selectivity), so the block bypasses non-new inputs.
- `grow_local_oracle` (UPPER BOUND, not valid): gate forced to 0 on all prior-stream prompts (uses old
  data) — shows the ceiling if the block were perfectly localized.
- reference: `ours_tgt_answerid` (replay positive), `naive` (frozen-isolation floor).

**Central question — and where I think it likely breaks (be critical):** our streams share the SAME
template (`"X's Y is"`); they differ only by *which subjects*, i.e. exactly the associations being learned.
So an output/gate localizer trained only on new-stream + anchor may fail to stay ≈0 on **old-stream**
prompts (same template, different subject) unless it keys on subject identity. If the localizer can't
separate old-vs-new stream prompts without old data, `grow_local_*` forgets like naive and the honest
conclusion is: **no-router isolation is impossible when streams are input-inseparable except by the learned
content** — a clean, fundamental negative that *earns* the growth-isolation bound (vs codex's prior).
