## Synth-data design (the part I want you to poke holes in)

Goal: facts that are (i) base-unknowable closed-book, (ii) mutually content-independent across articles,
(iii) expressible as natural-language QA WITH a valid paraphrase (answer-type preserving — the CF lesson),
using the SAME passage->QA template family as SQuAD. Design:

- **Invented proper-noun entities**, disjoint per article (random CV-syllable names: "Zelphar", "Qorin",
  "Braxil"), so no cross-article content overlap and base can't know them.
- **NAME/word answers, not numbers** (fixes the CF answer-type-change paraphrase break).
- A few relation templates, each with a question + a hand-written paraphrase:
  - "The capital of {land} is {city}." Q:"What is the capital of {land}?" / para:"Which city is the capital
    of {land}?" A:{city}
  - "The {org} was founded by {person}." Q:"Who founded the {org}?" / para:"By whom was the {org} founded?"
    A:{person}
  - "{person} discovered the {thing}." Q:"Who discovered the {thing}?" / para:"By whom was the {thing}
    discovered?" A:{person}
- One "passage" per article = a short paragraph concatenating that article's fact sentences; QA_PER facts.
- **Screen exactly like SQuAD**: keep only base-hard (base fails Q+para closed-book) AND RAG-answerable
  (gold-passage RAG gets Q and para right). This guarantees the same base-ignorance + RAG-upper-bound
  controls, so the ONLY axis differing from R38B is real-vs-synthetic corpus.

## The interpretation subtlety I want your read on

Synthetic like this still shares TEMPLATE structure (all "capital of X is Y"). Real SQuAD also shares
linguistic structure. What synth removes is **real-world semantic redundancy + pretrained-prior overlap**,
not format-sharing. So the contrast decides between three, not two, hypotheses:

- If synth zero-replay (k0) **collapses toward naive (~0)** while real held ~0.65 -> the real floor needs
  real-world redundancy/prior -> narrow clean positive ("structured real corpora leave a no-replay floor
  independent facts lack").
- If synth k0 **also holds ~0.6-0.7** -> the floor is generic objective gentleness (survives even with
  disjoint content) -> footprint thread fully closed, redundancy dead.
- Intermediate case I want to preempt: if synth holds ~0.65 it might be because template-sharing ALONE
  supplies enough shared structure. To separate "format redundancy" from "knowledge redundancy" I could add
  a second synth variant with **one distinct template per fact** (no shared question format across facts).
  Worth including that variant now, or is it over-engineering the first cut?

Also: should the synth paraphrase be template-swap (deterministic, as above) or LLM-generated like SQuAD
(Qwen2.5-3B)? Template-swap is cleaner/cheaper and avoids the paraphrase-quality confound, but it's an
easier paraphrase than SQuAD's LLM rewordings, which could inflate synth retention. I lean template-swap for
the first cut but flag it as a known asymmetry. Your call?
