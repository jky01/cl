## The finding: self ≈ oracle, so the bottleneck is NOT support drift

I expected self < oracle (imperfect self-support → compounding drift). Instead **self matches oracle and is
slightly BETTER on o2 (0.53 vs 0.32 at 4H)**, despite self-gen fidelity being only ~0.7. Consequences:

1. **The phase-3 degradation of o2 is capacity/interference, not generative drift.** Oracle rehearsal uses
   PERFECT true support + true labels and still drops o2 to 0.32 at 4H. So imperfect self-support is not
   what's hurting retention; three families competing in one fixed-width shared representation is.
2. **Self-generative rehearsal is a working mechanism.** It reaches perfect-replay quality (even a touch
   higher on o2 — plausibly because self-rolled support carries the model's own inductive bias / stays on
   the model's manifold, a mild consistency-regularization effect) using O(F) descriptor metadata
   ({orders seen}) and ZERO stored raw examples. This is the positive you asked for: the model reconstructs
   its own past support well enough to match oracle replay.
3. **o1 (arithmetic) is perfectly retained through 3 phases** in both self and oracle; the failure is
   concentrated in the harder higher-order families under three-way competition.
4. Why is self ≥ oracle despite 0.7 fidelity? The ~30% "invalid" self-support are not random garbage — they
   are sequences the current model actually produces, i.e. exactly the behavior we want to preserve, and
   they still pin the shared function on-manifold. Fidelity-vs-true-recurrence undercounts their usefulness.
   (I'll verify with the alternative fidelity metric you suggested: agreement between the OLD model's rolled
   support and the NEW model, separated from true-recurrence validity.)

## Honest reading

This is NOT a clean self≈oracle≈1.0 win; it's **self≈oracle, both above a hard capacity ceiling** that
degrades o2/o3 by phase 3. Mapping to the project: recursive self-generative consolidation genuinely
retains old FAMILIES into shared weights with no stored data and no inference memory (o1 perfect, o2/o3
partial), but a FIXED-WIDTH model hits a stability–plasticity ceiling at three interfering families that
perfect replay cannot overcome. That ceiling is exactly where GROWTH necessity should finally be probed —
the interference is now demonstrably not a replay/support artifact.
