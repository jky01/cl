## The deep point: gating needs a label-free router, which is our core problem in its sharpest form

To make the new branch silent on old-rule inputs and active on residual inputs, the model must decide
*at inference, without labels*, whether an input is "explained by the current rule" or "residual". That
is the same self-addressing/surprise-routing problem we have circled all along — but the toy has now
compressed it to its cleanest statement:

> Can the model produce a label-free gate g(x) ∈ [0,1] that is ≈0 on rule-following inputs and ≈1 on
> residual inputs, using only the old rule-model's own signals?

The natural candidate signal is exactly a residual/surprise score of the frozen old branch — e.g. its
max-softmax confidence or margin on x. Rule-following inputs should be confidently handled by the old
branch (high margin → gate 0); genuine residual/exceptions should be low-margin under the old branch
(→ gate 1). If that gate works, the combined output is `old_branch(x) + g(x)·new_branch(x)`, and it
should recover rule-1 (gate suppresses new branch on rule inputs) while keeping rule2/exception acc
(gate opens on residual).

Two design questions before I build the gate:

1. **Gate signal:** old-branch max-softmax / margin (cheap, label-free, purely from the frozen rule
   model) vs a small learned gate trained on the referee to predict "is-residual". The learned gate is
   stronger but needs a training signal (the referee tells it which inputs are residual — but only for
   the retained referee, so it must generalize to unseen inputs). I lean starting with the
   *unlearned margin gate* (falsifiable, no extra memory) and adding the learned gate as arm 2.
2. **Gate failure mode to watch:** the hard case is a residual that the old branch is *confidently
   wrong* about (an exception that looks rule-following to the old model). The margin gate would fail
   to open there. That's precisely the residual that a pure surprise signal cannot catch — and it may
   be the honest limit of label-free routing. Do you expect the margin gate to work for rule2 (a
   coherent second rule the old model is uncertain about) but fail for atomic exceptions (which the old
   model may be confidently wrong about)? If so, that asymmetry is itself the finding: gating rescues
   *structured* residuals (which are genuinely surprising to the old rule) but not confidently-wrong
   atomic ones — which dovetails with "grow only for compressible residuals."
