# Design discussion: a LEAST-ACTION principle for continual-learning memory writing

The user (project lead) proposed an original framing and asked for your adversarial cross-examination.
This is a strategy/design discussion — please attack it hard, then tell us the next step. No pod yet.

## The user's proposal (verbatim intent)

The genuinely creative move is: **don't train the whole model — train/select the WRITE PATH.**
Define writing new knowledge into memory / value-latent as a low-ACTION trajectory, with a single
action functional constraining decodability, retrievability, low interference, and low forgetting:

```
S_write = L_decode + λ·L_retrieve + α·Drift + β·Conflict + γ·ForgettingRisk
```

Not "least action for NN training" in general — specifically **least action as a continual-learning
memory-writing PRINCIPLE**: the write is the minimizer of S_write over a trajectory.

## My assessment (Claude), for you to check/attack

**(1) The five terms are a UNIFICATION of things we already have, not new individually:**
- `L_decode` = QA answer-seq CE (have); `α Drift` = neutral-anchor KL (have); `β Conflict` =
  `nswrite` null-space write (have); `γ ForgettingRisk` = surprise / retention-risk critic (R40/R41,
  have); `λ L_retrieve` = read-addressing (keytie tried → FAILED +0.06, retired).
- The real contribution is the **variational packaging**: from "scattered loss patches" to "one
  action whose minimizing trajectory IS the write." This is isomorphic to the reframe we converged on
  (`addressable low-interference write/read allocation`) — it gives that sentence a Lagrangian.

**(2) The fork: PRINCIPLE vs rebranded weighted loss.** If `S_write` is just `Σλᵢ Lᵢ` minimized by
SGD, least-action adds nothing. To earn the name it needs TWO things:
- **trajectory**: optimize the whole path M_{t-1}→M_t (variational ∫L), not greedy per-step SGD;
- **metric**: Drift/Conflict are DIRECTIONAL (moving along old-knowledge Fisher directions is
  expensive, orthogonal is cheap), so the right object is a **geodesic under a metric tensor**, not
  an isotropic scalar sum. The strong version = **optimal-transport / natural-gradient write**:
  minimal output-distribution perturbation that makes the new fact decodable.

**(3) Honest prior-art placement:**
- **ROME/MEMIT** (model editing): closed-form MINIMAL-NORM weight update inserting a fact while
  preserving other outputs ≈ the `L_decode + α Drift` least-action write already exists as a cousin.
- **Natural gradient / EWC**: Fisher-metric updates. We tested EWC → WEAK (0.456 vs replay 0.890),
  which warns that a Drift metric term ALONE is insufficient.
- What is genuinely new vs those: (a) continual TRAJECTORY not a one-shot edit; (b) explicit
  forward-looking `γ ForgettingRisk`; (c) `L_retrieve` folded into the SAME action.

**(4) The limitation the principle does NOT remove:** λ,α,β,γ are hand-set, and the learn-vs-retain
tradeoff is THE core CL difficulty. Least-action reformulates it cleanly but does not TELL you the
weights — it moves the hard problem into a cleaner container. Also `γ ForgettingRisk` is a prediction
about a NON-STATIONARY future you can't see; our surprise/bits-token proxy is a heuristic dressed as
principle. Don't let the math's elegance hide that.

**(5) Why I still think it's worth building — it generates the right experiment.** `nswrite` is the
HARD-constraint version of β Conflict (move only in the null-space of old gradients) and it
SATURATES (subspace occupancy 0.74→0.91). The action view immediately yields the SOFT version:
penalize movement weighted by the old-Fisher metric instead of forbidding it. Hypothesis:
**soft-metric (OT/natural-gradient) write degrades GRACEFULLY past the point where hard null-space
saturates**, at zero replay — a clean, falsifiable, rehearsal-free test that hits the real frontier
gap we named (interference, not rehearsal).

## Questions for you (attack these)

1. **Is this more than natural gradient / K-FAC / online-EWC?** State precisely the difference. My
   claim: EWC = diagonal-Fisher penalty on a POINT update; the proposal = a metric geodesic over a
   TRAJECTORY plus retrieve + forward forgetting terms. Is that a real distinction or am I dressing
   up a known method? Where exactly would soft-metric write diverge from natural gradient in
   behavior?
2. **Can the strong (OT/geodesic) version be computed at 0.5B?** Full Fisher is intractable; K-FAC or
   a low-rank / diagonal + neutral-probe empirical output-drift metric is the realistic proxy. What
   metric approximation would you use, and does it stay rehearsal-free (metric estimated from a
   frozen base + a small neutral probe set, NOT from replayed old items)?
3. **Does folding `L_retrieve` into the action rescue read-addressing where keytie FAILED?** keytie
   anchored the key location and gained almost nothing (+0.06). Is "retrievability as an action term"
   a different mechanism, or the same dead end in new notation?
4. **Is `γ ForgettingRisk` legitimately includable?** It predicts future interference from a
   non-stationary stream. Is a frozen-base surprise proxy defensible inside an action, or is it a
   category error to put a future-prediction heuristic in a variational functional?
5. **What is the single cheapest experiment that would prove the geometry EARNS ITS KEEP** — i.e.
   soft-metric write beats (a) plain SGD write and (b) hard null-space `nswrite` on
   old-retention-at-matched-new-decodability, rehearsal-free? Propose the minimal arm set + metric +
   pass/fail, so we can decide whether this goes to a pod.

Push back where I'm wrong. If you think this is a rebranding of natural gradient, say so plainly.
