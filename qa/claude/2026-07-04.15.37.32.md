## R32 gate 結果（3 seeds, RTX 4090, pod 已回收）

| 指標 | 值 |
|---|---|
| single-step seen/para（A→B, B→C） | **全 1.000** |
| held-out 2-hop A→C（seen / para） | **0.000 / 0.000**（goldC-prob 2.5e-8） |
| derange 控制 / base-untrained | 0.000 / 0.000 |
| **Gate A** | **FAIL** |
| Gate B direct-2hop：train-fit / held-out | **1.000 / 0.000** |
| **Gate B** | **FAIL** |

**判讀**：單步知識完美進權重，但 latent（無 CoT、無記憶）held-out 2-hop composition **完全是 0**；直接監督 2-hop 也只是記住訓練對（train-fit 1.0），對新鏈 **零泛化**。這就是 two-hop curse / OOD compositionality gap，在 0.5B + 此預算下**上限模型本身就做不到**。Gate B 的 train-fit=1.0 反過來**驗證了評測管線正確**（能 compose 時分數就會出來），所以 0.0 是真的、不是 bug。

**結論**：cross-stream **latent held-out** composition **不是**能撐起 growth 的壓力源——上限都 0，grow-vs-fixed 會是 0-vs-0、不可歸因。gate 正確地**擋下**了這組 arms（這正是它的用途）。這條路就像 R31 封掉 fact-count 一樣被封掉了。

## 現況：三條 growth 正當性路都已封（0.5B 尺度）

1. **retention**（R23）：replay 而非 growth 防遺忘。
2. **capacity**（R31）：固定 1 層 + replay 就 hold 800 facts。
3. **latent composition**（R32）：上限模型 held-out 2-hop = 0。

## 下一輪：兩個候選，我推薦先做 (B)

### 候選 A：in-distribution composition **grokking** 探針（最後一條可達的 growth 路）
- 文獻（Grokked Transformers are Implicit Reasoners, 2024）：latent 2-hop **可以**學會，但要**遠超 overfitting 的長訓（grokking）**，且**只在 in-distribution 泛化**（held-out 實體/事實不泛化——正好對上我們 Gate B 的 0）。
- 因此要改成：訓練**混入部分 2-hop**（同一實體池），只 held-out「哪些 (A,C) 被詢問」，其原子事實與實體都在其它 2-hop 訓練樣本中出現過。再問：**depth/growth 是否縮短 grokking onset 或抬高 in-distribution ceiling**。
- **成本/風險**：grokking 復現很 finicky，pretrained 0.5B + tiny synthetic 未必 grok；可能燒很多 GPU 得到又一個負結果；且就算成立，也只是「depth 幫助 in-distribution 推理湧現」的窄主張。**必須設硬 kill criterion**（step 上限 + 若 N step 內 held-out 仍 0 就停）。

### 候選 B（我推薦先做）：**baseline bakeoff**，把「已證的 replay-consolidation」變成有對照的貢獻
- 現況缺口：我們有 R30 可靠迴路（replay 防遺忘、無 inference memory、無 joint retraining），但**還沒跟標準 continual-learning 方法正面比**。roadmap R23 原本就點名 continued-PT / LoRA-merge / naive-copy，但只跑了 grow-vs-nogrow。
- 直接對上專案目標（AGENTS.md：知識進權重、不災難性遺忘、**不靠 joint full retraining**）：在同一 6-stream 生命週期上比 arms：
  - **replay-consolidation**（我們的，no gold、no inference memory）
  - **sequential full-FT**（無 replay，預期災難性遺忘——已有 naive 對照，正式化）
  - **LoRA-merge**（每 stream 訓 LoRA 後 merge 進權重）
  - **continued-PT**（單純在新 stream 上續訓）
  - **frozen + external memory**（R10-R18 的舊路，當「靠外部記憶」的對照）
- 報告：oldest-stream forgetting、all-stream seen/para、base-hop preservation、可訓練參數/compute、**是否需要 inference memory**。
- **價值/成本**：便宜、幾乎確定產出**正面比較結果**（我們的迴路 vs 已知方法），把「knowledge-into-weights via replay」從「我們做得到」升級成「**優於標準 baselines**」。這比再拿一個 growth 負結果更推進專案。
