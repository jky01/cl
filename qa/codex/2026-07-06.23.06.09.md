## Oracle paradox

The oracle result is now a robust sub-finding, and it is important. `grow_local_oracle` drives `delta_old_final` to
`0.001`, yet old recall collapses worst: `all_seen = 0.177`, oldest forgetting `+0.8875`. Newest is still `0.8875`, so
this is not a plasticity-collapse explanation.

Interpretation: **hidden-space new-block identity is not answer preservation.** In this lifecycle, forcing each new
block to be almost inert on old prompts can remove transformations the final dense path now needs for old recall. The
new grown blocks are not harmless add-ons; even their old-prompt footprint can be part of the current answer function.
That is why the footprint-retention relation is non-monotone:

- oracle: `delta_old ~= 0.001`, retention worst;
- decoy: `delta_old ~= 0.054`, retention best among local arms;
- anchor: `delta_old ~= 0.078`, retention below naive.

Also, `grow_local_decoy` has a noisy `delta_old_curve` with a round-4 spike (`0.3612`) before ending low. The mechanism
is not clean monotone locality control; it is a noisy regularizer that happens to provide a bounded retention gain.

## Project objective assessment

- **Knowledge into weights:** yes. New facts are trained into the dense model; there is no inference-time memory.
- **Continual retention:** partial. Decoy improves over naive but leaves large forgetting and trails both `nswrite` and
  replay.
- **Growth necessity:** not established. Since `grow_local_decoy` is below fixed-size `nswrite`, growth is not the
  likely driver. The `BK_LOCAL_NOGROW=1` control is mandatory before any growth claim.
- **Compute advantage:** not established. The local-growth arms are not cheaper than the fixed-size frontier; decoy is
  slower/heavier than naive and below `nswrite`.
- **No joint full retraining:** satisfied. This is sequential training and not full-history joint learning.

So R37-A currently advances the project by mapping a boundary: no-router localized growth can reduce interference
slightly with generated unlabeled coverage, but hidden-footprint isolation is not enough for durable in-weights
continual retention.
