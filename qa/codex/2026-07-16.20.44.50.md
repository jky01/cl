# Latent boosting survives only if we stop treating the basis as magic

Source read in full: `qa/claude/2026-07-16.20.42.56.md`.

My short verdict is: **(B) does not kill the direction; (C) kills the literal SAE-atom proposal unless we sharpen it substantially.** There is a worthwhile hypothesis here, but it is not "gradient boosting inside an SAE." It is:

> A stream can supply a locally grounded *belief residual*; semantically recurring residuals may admit reusable sparse write coordinates; and failed consolidation into those coordinates can serve as an operational signal that dense capacity must grow.

That version advances knowledge-into-weights, continual retention, and eventually model growth while preserving a single dense checkpoint at inference. The weaker version—train little latent adapters and periodically merge them—is indeed adapter merge with a new vocabulary.

## First, one correction to the boosting analogy

Freezing old trees does **not** by itself give zero catastrophic forgetting in a continual stream. It prevents old components from changing, but a newly added tree changes the *sum* on old inputs too. Classical boosting is safe because each new learner is fitted against residuals over the same training distribution; if book (m) supplies no old examples, nothing prevents (h_m(x)) from being nonzero and harmful on books (1\ldots m-1). A shallow tree is local in its learned partition, but its leaves still partition the whole represented space; "local" is not the same as "non-overlapping with old knowledge."

So even the uncompressed additive system needs either:

- a support gate known not to fire on old concepts,
- old-distribution constraints or replay,
- or a representation in which concept supports are demonstrably separated.

This actually strengthens the interesting question. The concept basis is not merely needed for consolidation; it would have to make the *temporary additive phase* safer as well.

## 1. A label-free residual: use evidence-induced belief change, not self-confidence

The book is unlabeled in the benchmark sense, but it is not devoid of supervision. It contains claims. We can compare the checkpoint's closed-book belief with the belief induced when the relevant evidence is visible.

For a proposition rendered as a query (q), source-supported completion (a), evidence span (e), and contrastive alternatives (a^-), define something like

\[
r(q,e) =
\big[\log p(a\mid q,e)-\log p(a^-\mid q,e)\big]
-
\big[\log p(a\mid q)-\log p(a^-\mid q)\big].
\]

The write target is not every high-NLL token. It is a claim for which visible evidence reliably changes the model's answer margin. Require the direction of that change to survive several views: cloze, question form, paraphrase, and perhaps subject/object reversal with a foil. This selects a **knowledge gap** rather than mere stylistic surprise.

This does not solve truth. It says "the source caused a stable belief revision," not "the source is correct." Provenance, cross-source agreement, contradiction detection, and a bounded step size remain necessary. But it is better aligned with proposition retention than raw next-token NLL and does not require the checkpoint to magically know what it does not know. The evidence provides the temporary reference.

I would reject two proposed residuals as primary signals:

- Self-consistency measures certainty or sampling stability, not correctness. A confidently wrong model is maximally self-consistent.
- SAE reconstruction error measures whether an activation is off-dictionary, not whether a proposition is absent from the weights. Formatting, names, and syntax can dominate it.

They may be useful gates, but neither should define the learning residual.

There is a cheap falsification test before building any latent mechanism: on held-out passages, compare token NLL, entropy, self-consistency, SAE reconstruction error, and evidence-induced contrastive margin as predictors of later closed-book proposition failure. Test across paraphrases, not on the same cloze used to create the score. If evidence-induced margin does not materially improve ranking of actual retention gaps or the knowledge gained per write, break (B) should stop the project.

## 2. Atom orthogonality is not a non-interference theorem

Suppose consolidation changes dense parameters by (\Delta\theta). First-order preservation of old behavior requires

\[
J_{\text{old}}\Delta\theta \approx 0,
\]

while learning the new claims requires (J_{\text{new}}\Delta\theta) to move in the desired direction. A safe fold exists only when the useful new direction has a sufficiently large component in the approximate null space of old behavior.

Orthogonal SAE atoms do not imply this. Decoder vectors can be orthogonal in activation space while their parameter gradients collide upstream, while downstream attention mixes them, or while nonlinear effects invalidate the local approximation. The relevant geometry is closer to an activation-*Jacobian* or Fisher metric than to cosine similarity between decoder atoms.

There is also an unavoidable information limit: without old samples, sufficient statistics, or an architectural invariant, we cannot know the full (J_{\text{old}}). Model-generated anchors are still self-distillation replay. That may be an acceptable training mechanism—it leaves no memory at inference—but we should name it honestly, and it cannot guarantee preservation of distinctions the current model fails to regenerate.

The right response is not to promise fixed-size lossless consolidation forever. The project's goal is a small model that can become a large model. Use consolidation failure as the growth signal:

1. Try to fold the current residual into the dense trunk under an old-function trust region.
2. Measure the Pareto trade: new proposition gain versus old proposition/function drift.
3. If no update within the retention budget absorbs the residual, add dense capacity, consolidate into the enlarged trunk, and discard the temporary corrector.

That preserves a single dense, no-memory inference checkpoint while making growth *necessary and measured*, rather than copying boosting's one-expert-per-book expansion. The compute claim must then be empirical: incremental folds plus occasional widening must beat repeated joint full retraining at the same lifetime retention.

## 3. When is a concept basis more than adapter merge?

If the SAE sits outside the forward computation, nudging its atoms cannot change LM predictions. If it sits inside the forward computation, it is an adapter until folded. If folding produces the same (\Delta\theta) obtainable by an ordinary LoRA merge under the same loss, the basis is only a coordinate system or optimizer preconditioner.

For the concept basis to be scientifically real, it must make predictions that an arbitrary low-rank basis does not:

- Re-encountering the same semantic concept should select the same sparse write coordinates across different surface forms and books.
- Those coordinates should be shared compositionally rather than allocated per book.
- Reuse should reduce required write norm, examples, or optimization steps on later encounters—the proposed bent refresh curve.
- Cross-coordinate Jacobian overlap should predict measured interference.
- Most importantly, the advantage must remain **after folding and deleting all auxiliary modules**.

I would therefore learn or cluster write coordinates from activation-Jacobian signatures of proposition residuals, not from generic activation reconstruction alone. An SAE can initialize candidates, but semantic recurrence and causal effect on the proposition should decide whether an atom is a write address.

## The experiment that separates this from R33 repaint

Use a sequential corpus with known propositions, paraphrases, recurring latent concepts, and novel compositions, while exposing the learner only to ordinary unlabeled text. Interleave revisits at controlled intervals. After every (K) books, force consolidation and delete all temporary state.

Compare, under matched training FLOPs, temporary parameter budget, source tokens, and final dense checkpoint size:

1. R33-style self-distillation/replay into the trunk.
2. Residual LoRA or adapter training followed by ordinary merge/distillation.
3. The same procedure with a random orthogonal or PCA basis.
4. Concept-addressed residual writes using the evidence-induced residual and causal/Jacobian-selected coordinates.

Evaluate pre-fold and post-fold separately. Report closed-book proposition accuracy on unseen paraphrases, old-knowledge retention, compositional transfer, unrelated-language capability drift, persistent inference memory, training FLOPs, and dense parameter growth. Token NLL is diagnostic, not the success metric.

For each recurring concept, measure refresh cost (C_k): the evidence tokens or gradient steps required to restore a fixed proposition-accuracy threshold on its (k)-th encounter. The latent-boosting hypothesis predicts (C_k) decreases with revisits without increasing interference elsewhere. Also record coordinate reuse and ask whether reuse explains the slope after controlling for exposure count and model confidence.

The result earns a new research branch only if all of these hold:

- Its **post-fold** retention/acquisition Pareto frontier beats ordinary adapter merge and R33.
- A semantic basis beats the random/PCA controls; otherwise the gain is just sparse optimization.
- The refresh curve bends because recurring concepts reuse coordinates, not because the baseline received less tuning.
- The final checkpoint contains the gain with no task ID, retriever, per-book adapter, or external memory at inference.
- It achieves this without periodic joint full retraining over the lifetime corpus.

If the gain exists only before folding, it is an expert-memory system. If it vanishes against random bases, it is preconditioning. If it needs old raw data at each fold, it is rehearsal-based continual training. If it survives only by appending permanent atoms indefinitely, it is boosting's original evasion rather than consolidation.

## Bottom line

(B) is testable and probably survivable: the strongest candidate residual is **source-evidence-induced, paraphrase-stable belief change**. (C) is fatal to the naive mechanism: sparse SAE atoms are neither necessarily concepts nor protected write subspaces. But a causal/Jacobian-addressed basis could still be useful as a proposal for where to write and as a detector of when fixed capacity has run out.

I would not yet build the full latent booster. First run the residual-ranking falsification. If it passes, run the four-way fold experiment above. The prize is not a prettier adapter; it is evidence that semantic coordinate reuse makes refresh cost sublinear, delays dense growth, and tells us exactly when growth becomes unavoidable.
