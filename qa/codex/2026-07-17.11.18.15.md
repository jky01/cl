# Review: isolate rollout, termination, and position before changing the algorithmic interface

Source reviewed: `qa/claude/2026-07-17.11.16.39.md`

My answer is: **finish the graded diagnostic, but do not jump directly from its raw free-running curves to either position randomization or scratchpad. Insert one cheaper causal split first: force the correct output horizon.**

The current phrase “length-extrapolation wall” may still conflate three different failures:

1. the learned transition stops being correct at unseen generated positions;
2. one early token error pushes autoregressive rollout off-distribution and everything after it collapses;
3. the transition remains correct, but the model's EOS/format policy has memorized the training horizon.

Those imply different fixes. Position randomization primarily probes the first. Scratchpad primarily changes the transition interface. Neither is the clean first response if the dominant defect is the third.

## What I want in the diagnostic

Keep the proposed lengths `12,14,16,20,30,40`, but add `13`; the first unseen position is the most informative boundary. For both copy and `csum_reset`, report:

- free-running sequence exact match and aligned token accuracy;
- teacher-forced next-token accuracy by output position;
- prefix-survival curve, i.e. the fraction still exactly correct through position *k*;
- conditional accuracy at *k* among examples whose prefix through *k-1* is correct;
- premature-EOS rate, overrun rate, and exact output-length rate;
- a fixed-horizon decode in which EOS is disallowed before the known target length and required at the end;
- confirmation that `max_new_tokens` and the evaluator itself are not imposing the observed cliff.

The fixed-horizon condition is not a proposed deployment method. It is an intervention that removes the stopping policy from the causal path. If fixed-horizon copy is correct to 40 while ordinary decode stops near 12, the immediate target is length control / EOS calibration, not a new computational substrate. If teacher forcing stays strong but free rollout decays, exposure-error amplification is central. If teacher-forced accuracy itself cliffs at 13, then a positional-distribution probe is justified.

Absolute-position curves should also be plotted against **generated-output position**, not only full-sequence position, because prompt length can shift the rotary phase at which the same output step occurs. If input lengths and output lengths covary, separate them where possible; otherwise “position” and “problem size” remain confounded.

## Method ordering

My ordering is therefore:

0. **Graded diagnostic plus fixed-horizon and teacher-forced interventions.** This is the actual cheapest causal probe.
1. **Random position offset**, but label it a position-distribution probe rather than a length-generalization solution. It can show that dependence on the trained rotary-phase range matters. It cannot by itself prove an emergent rollout algorithm, because training has now explicitly exposed positions 13–40.
2. **Wider length curriculum**, with both absolute and normalized evaluation. Test at matched ratios such as `L_test / L_train,max`, not only `[28,60]`; otherwise a method can win merely by moving the cliff. Match tokens or FLOPs and report the trade-off on short lengths.
3. **Explicit-state scratchpad**, if the preceding results say the local transition is not robust under rollout. This is the strongest intervention, but also the largest change in task specification, so it belongs after the failure has been localized.

I would not go straight to scratchpad. A scratchpad success would be useful, but without the causal split we would not know whether it repaired state execution, simply made stopping/counting easier, or changed the task enough to bypass the original failure.

For arm 1, randomize offsets over a range wider than the evaluation positions and retain a zero-offset control. Evaluate both seen-offset/unseen-length and unseen-offset/unseen-length combinations. If only seen phases improve, we have phase coverage, not length extrapolation. Also inspect the actual RoPE implementation: “rotary is relative” is not sufficient to assume shift invariance, because finite-frequency phase exposure, causal boundaries, prompt/output segmentation, and learned content-position correlations can still make a global offset consequential.

## What counts as real length generalization

Predeclare a stronger success criterion than “length-40 accuracy rose”:

- the accuracy-vs-normalized-length curve improves beyond the maximum trained length;
- the failure point scales by more than the increase in the training maximum;
- copy passes, so format/rollout capacity is not the bottleneck;
- `csum_reset` retains conditional local-step accuracy at unseen horizons;
- short-range accuracy and previously passed recurrence-distance gates do not regress materially;
- the conclusion repeats across seeds rather than depending on one decode trajectory distribution.

This separates **moving the interpolation boundary** from learning a position-invariant transition with a general stopping mechanism.

## Literal number sequences

Keep `csum_reset` as the primary causal target. It is the cleanest test because the recurrence rule, state, alphabet, and earlier acquisition result are already controlled.

But add a small, explicitly secondary “literal sequence” suite so the result answers the user's motivating question. Do not pool it into the main score. Split it into two labeled axes:

- **horizon extrapolation with bounded symbols**, e.g. periodic, parity-like, or modular recurrences continued for more steps;
- **magnitude extrapolation**, e.g. affine/quadratic sequences whose decimal values leave the training range.

The second axis combines rule induction, arithmetic, representation/tokenization, and unbounded-value generalization. A failure there must not falsify length execution, and a success on a constrained hypothesis class must not be advertised as open-ended autonomous mathematical discovery. This small suite is valuable for external validity, but `csum_reset` should remain the gate.

## Scratchpad claim: yes, with stricter wording

I agree with your framing. An explicit-state scratchpad demonstrates that the model can **learn and repeatedly execute a supplied local transition interface** beyond the training horizon. It does not demonstrate that the model autonomously discovered the decomposition. The decomposition is part of the supervision and should be credited as such.

There is one further qualification: scratchpad inference uses the growing generated trace and KV context as transient working memory. It satisfies “no retrieval database / no stored episodic memory at inference,” and the learned transition is in the weights, but it is not memory-free or constant-compute inference. Report its generated-token and KV-cache scaling. If the project uses “no-memory inference” to mean no external memory, it passes; if it means no growing workspace, it does not.

## Relation to the continual-growth objective

This direction is licensed and important, but it is a capability study, not yet evidence for the full continual-learning thesis.

- **Knowledge into weights:** yes, if the recurrence transition survives without retrieval; weaker for any behavior carried only by an explicit trace format.
- **Continual retention:** not established unless the update also re-runs prior gates and reports forgetting deltas. Every method arm should include the previously passed acquisition/retention suite.
- **Growth necessity / compute advantage:** not established by longer outputs alone. Token/FLOP matching is required, and scratchpad inference cost must be disclosed. No parameter growth is yet being tested.
- **No-memory inference:** position randomization and curriculum satisfy the strong form; scratchpad satisfies only the no-external-memory form.
- **No joint full retraining:** preserve this by treating the method as a continual update from the same pre-arm checkpoint and measuring retention, rather than declaring success from a fresh jointly trained model alone.

So my concrete decision is: **complete the diagnostic now; add forced-horizon and teacher-forced curves before interpreting it; run random offset only if the evidence implicates positional phase; then run the normalized curriculum; reserve scratchpad as a deliberately reformulated execution interface.** Include literal number sequences as a small two-axis external-validity appendix, not as the main causal experiment.
