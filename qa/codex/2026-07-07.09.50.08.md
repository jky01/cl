## Verdict

I agree with the retraction. The hardened R38B result is not a weaker version of the original footprint
claim; it changes the claim's sign and attribution. After the old-only split correction, the pass bar I
asked for is clearly missed:

- K3 old-only non-replayed paraphrase is only `0.687` vs K0 `0.625`, a `+0.062` average gain, far below

- Seed behavior is not stable: seed0 makes K replay look flat or harmful, seed1 makes it look mildly
  helpful.
- `k0_noanchor` is the best non-replayed retention arm in both seeds (`0.675`, `0.800`; avg `0.738`),

So the strong claim "real-text redundancy softens O(#facts) replay coverage" should stay retracted. The

the run does not show reliable spillover to unreplayed neighboring facts.

This does not weaken the core R38-A bridge. It narrows it. The bridge still says: passage text can be
converted into QA/answer-function targets and consolidated into one dense checkpoint with closed-book
paraphrase recall, no inference memory, and no full joint retraining. What failed is the attempted
sub-O(#facts) replay-footprint extrapolation.

## Ranking of next moves

My ranking is **A first, then B, with C separate and lower priority for this specific decision**.

### A. Same-objective synthetic control

This is the right next move because it resolves the only clean remaining question in the footprint thread:

> Is the K0 / no-old-replay floor a real-text shared-structure effect, or just the generic consequence of a
> gentler QA consolidation objective?

But it has to be a same-objective control, not merely "run the old synthetic bakeoff again." The primary
control should match R38's relevant properties:

- fixed-size dense checkpoint, or at least a primary `LD_GROW=0`/no-growth condition, because R38B did not
  rely on per-round growth;
- new-answer CE or teacher answer-function consolidation from `M_{t-1}`;
- zero old replay;
- anchor and no-anchor variants;
- old-only final split, excluding the final stream from the forgetting claim;
- `naive`/continued-PT destructive floor and full-replay reference.

`s2/lifecycle_bakeoff.py` is the right place to implement this because it already has independent
synthetic facts, replay-K accounting, old/nonreplayed metrics, and the no-inference-memory flags. The
main caution is that its current `run_consolidate()` grows every round by default and has its own
base+hop anchor path, so the control should explicitly remove or bracket that confound.

Pass/fail interpretation:

- If independent synthetic zero-replay consolidation collapses near naive while real text stays around
  `0.63-0.74`, then the real-text floor is a real shared-structure result. That would not resurrect the K3
  footprint claim, but it would open a cleaner "structured corpora allow some no-replay retention" claim.
- If synthetic zero-replay also holds around `0.6-0.7`, then the R38B floor is objective gentleness, not
  real-text redundancy. The footprint thread is closed: gentle consolidation helps, but reliable retention
  still needs item coverage or a new writer.
- If no-anchor beats anchor in synthetic too, the anchor harm is a generic base-prior interference effect.
  If it only happens in WikiBridge, inspect anchor distribution mismatch and answer overlap.

### B. Fold the footprint result into the capstone / pivot

After A, yes: fold R38/R38B into the capstone and move on. But I would phrase B carefully because the
current `FINDINGS.md` already says R36-I/nswrite is mapped and bounded: it is a real rehearsal-free
improvement over naive writing, but it remains well below replay and the input-direction family appears
limited.

So the post-A pivot should not be "try more nswrite tuning" unless there is a genuinely new mechanism. The
capstone line should be:

- R38-A: real text can be converted into closed-book in-weight QA knowledge.
- R38B: random small replay does not provide neighbor spillover; per-item coverage still matters.
- R36-I: rehearsal-free interference-aware writing improves the floor but does not yet solve retention.
- Next mechanism must either reduce training-time replay footprint with stronger coreset/target selection,
  or introduce a new writer that preserves answer function more directly than input-direction protection.

That keeps the project aligned with the objective: knowledge goes into weights, inference is memory-free,
catastrophic forgetting is measured directly, and growth is not invoked until it buys a measured capacity
or compute advantage.

### C. Better CF typed-answer data

C is still important for the separate counterfactual claim, but it does not decide the R38B footprint
retraction. I would run it opportunistically, not before A. The CF blocker is "does base-unknown new
knowledge generalize across valid paraphrases?" The A blocker is "what caused the K0 retention floor?" A is
the cleaner branch point for the current thread.

## Anchor decision

I would change the consolidation recipe provisionally, not conclusively:

- For retention experiments, make `noanchor` the primary arm or at least a first-class arm. The R38B signal
  is directionally consistent across both seeds and affects both old-only nonreplayed retention and final
  paraphrase.
- Do not declare neutral anchors bad in general yet. R38B did not report a rich base-capability preservation
  curve, and the whole reason for anchors is to preserve base behavior while writing new knowledge.
- The next recipe should report a Pareto curve: old-fact retention, newest paraphrase, and neutral/base
  preservation under `noanchor`, low-weight neutral KL, and the current anchor. If current anchor loses
  retention without buying measurable base preservation, drop it.

The mechanistic hypothesis is straightforward: the base KL is neutral in prompt content but not neutral in
parameter effect. It pulls the checkpoint toward the pretrained prior, so it can erase newly learned facts
even when it never touches old QA prompts directly.

## Bottom line

Run **A first** as the final footprint-thread discriminator. If A says the K0 floor is objective gentleness,
close the redundancy claim and pivot. If A says real text uniquely preserves unreplayed facts under the
same objective, the new claim becomes narrower but more interesting: not "K replay gives sublinear
coverage," but "structured real corpora can leave a no-replay retention floor that independent facts lack."

Either outcome advances the main project because it clarifies what actually writes durable knowledge into
weights without inference memory and without joint full retraining.
