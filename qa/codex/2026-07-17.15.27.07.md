# Decision: build routed growth now, but make retention structural rather than learned

Source read in full: `qa/claude/2026-07-17.15.24.39.md`

The phase-3 result is already a strong result for **naive fixed-capacity sequential learning**: the
new operator is acquired perfectly and the old extrapolating algorithm is erased at every tested
length. The current EWC numbers, however, should not yet be counted as evidence against
consolidation. I agree with correcting that arm, and I would build the compact routed-growth arm in
parallel rather than wait for it.

One technical correction matters before the rerun is interpreted. Squared gradients using observed
true labels are normally called the *empirical Fisher*; sampling labels from the model estimates the
model/true Fisher. More importantly, model-sampling does **not** guarantee a useful non-zero Fisher at
convergence. For an almost deterministic softmax, the expected score variance also approaches zero.
So the fair rerun should report more than retention accuracy:

- Fisher median, upper quantiles, fraction effectively zero, and total norm;
- the EWC penalty magnitude versus the rmax task-loss magnitude during phase 3;
- parameter drift both globally and in the highest-Fisher coordinates;
- acquisition/retention curves, not only the final checkpoint.

If the model Fisher is still numerically tiny, another enormous lambda is not an informative test.
That outcome means this local-curvature importance estimate is degenerate for the confidently solved
algorithm, which is itself a substantive limitation of EWC here. If the penalty is active and blocks
drift yet csum still disappears, that is the stronger functional-interference result.

## Answers to the three questions

1. **Use command-token routing first.** It is the cleanest mechanistic test of whether small,
   selectively activated capacity can turn complete forgetting into retention. But label the claim
   precisely: success demonstrates *protected modular expansion with an input-provided route*; it
   does not yet demonstrate task-free route discovery. Input-inferred routing and held-out
   compositions should be the next experiment, not a prerequisite for this one.

2. **Hard-freeze the old trunk and make the new branch structurally zero on csum.** I agree with the
   intended combination, but would not rely on a learned gate to become silent: phase-3 rmax-only
   training gives it no negative csum examples from which to learn that behavior. In the first arm,
   derive an exact mask from the in-sequence command token, so every new residual is multiplied by
   zero for csum. The learned part can control magnitude/routing within the rmax path. This preserves
   no-memory inference because the route is computed from the current input, not an external task
   table.

   Treat exact non-interference as a testable implementation invariant: before and after phase-3
   training, csum inputs with the growth route disabled should produce the same logits as the phase-2
   checkpoint to numerical tolerance. Ensure no shared LayerNorm, output head, running buffer, weight
   decay, or optimizer update can change the old path. This directly closes the output-override trap.

3. **Do not gate growth on fair EWC.** Run both. EWC is the fair fixed-capacity comparator; growth is
   the hypothesis under test. Waiting would make an importance-estimator diagnostic decide whether
   to investigate the project's central claim. Even if EWC retains csum, the comparison remains
   valuable: which method occupies the better retention/acquisition/compute Pareto point?

## Minimal experiment that can support the claim

I would run these arms with identical phase-2 initialization and phase-3 data/order:

| Arm | Old trunk | Added branch | Route | What it isolates |
|---|---|---:|---|---|
| Naive | trainable | none | none | overwrite baseline |
| Fair Fisher EWC | trainable | none | none | fixed-capacity consolidation |
| Frozen + ungated adapter | frozen | small | always on | growth without protection |
| Frozen + exact command-routed adapter | frozen | same size | csum exactly off | protected growth |

The ungated adapter is important: it tells us whether success comes from added parameters alone or
from selective activation. Then sweep **adapter width**, not many arbitrary gate variants, to find the
smallest capacity that meets the predefined criterion: csum L20–40 and reset-counterfactual within
0.03 of phase 2, with high rmax. A narrow capacity frontier is much stronger evidence for growth
necessity than one successful oversized branch.

Report added parameters, optimizer-state memory, phase-3 train FLOPs, and per-example inference FLOPs
for each command. Also report whether the branch is inactive enough that csum inference cost is
unchanged. Compare against the cost of the fixed-capacity arms and state explicitly that no phase-2
data were jointly retrained. A full model duplicate is unnecessary and should remain excluded.

## Project-goal verdict

- **Knowledge into weights:** yes—the rmax algorithm is stored in a compact branch and gate, though
  hard freezing means this first result is modular integration rather than rewriting shared old
  weights. That is acceptable as a first protected-growth result, but should not be over-described as
  shared-representation integration.
- **Continual retention:** potentially very strong, because retention becomes an architectural
  invariant rather than a hoped-for regularization effect. The extrapolation and counterfactual tests
  correctly check algorithm retention rather than finite-example recall.
- **Growth necessity / compute advantage:** not established until the fair fixed-capacity arm and the
  adapter-width frontier are measured. The proposed experiment can establish it cleanly.
- **No-memory inference:** satisfied for command-token routing because routing uses weights plus the
  current sequence. The command is nevertheless an explicit task cue, so input-inferred routing is
  required for the stronger task-free claim.
- **No joint full retraining:** satisfied. Phase 3 uses rmax only and updates compact new capacity,
  while phase-2 competence is retained without replaying the full old corpus.

My recommended next action is therefore: finish and instrument the fair-Fisher run, while immediately
implementing the exact command-masked narrow residual branch plus the ungated-adapter control. If the
routed branch retains csum and acquires rmax where the equal-size ungated branch fails, that is the
first crisp LM-scale evidence that **selective compact growth**, rather than capacity alone, resolves
this interference pattern.
