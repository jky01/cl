## Caveats on R36-EV

The newest-stream caveat is not a threat to the retention claim, but it is a protocol warning. Seed 0 stream 5 had scaffold answer-recall 0.53, and both `ours` and `oracle` ended at 0.525 on that stream. Seed 1 stream 5 was 0.98/0.97. So the mean newest 0.75 is not evidence that replay-consolidation cannot learn fresh KG facts; it is a mixed scaffold/data-quality issue. If the pre-registered clause was "every teacher answer-recall must be >= 0.80", then seed 0 S5 violates it. I would keep R36-EV as a pass, because the failure hurts all replay arms equally and does not inflate old retention, but future KG runs should gate per-stream, not only mean, teacher recall.

The oracle gap is now clearly para-dominated: seen gap +0.035, para gap +0.131. That is the known cost of no-gold self-distill, not a refutation of consolidation. It matters for the paper claim if we emphasize paraphrase generalization, but it should not block the rehearsal-free boundary test.

## Is Option C materially different?

Yes, but only if implemented as an answer-level Jacobian/OGD arm, not as another activation-only GPM label.

Current `nswrite` in `s2/lifecycle_bakeoff.py` protects each trainable Linear locally:

```text
project G away from old input basis U
equivalently constrain local Linear response: Delta W U ~= 0
```

That preserves a per-module linear response on stored old input directions. The R36-I failures show that this does not preserve the old answer through the later nonlinear network, normalization, residual interactions, and logit margin.

An OGD-style arm should instead store a low-rank basis of old answer-level gradients, for example:

```text
q_i ~= d old_margin_i / d theta_trainable
project current flattened gradient: g <- g - Q(Q^T g)
```

This is first-order protection of the old answer objective itself. It can catch downstream sensitivity that `U_in` cannot. So it does not collapse to the same bound in principle.

But implementation discipline matters. If "GPM" is just per-layer old activation bases with local gradient projection, it is basically the same family as `nswrite` and not worth a pod. The live test is specifically an answer-Jacobian OGD/GPM variant.

## Concrete C experiment

Add one arm to `s2/lifecycle_bakeoff.py`, probably named `ogd_head` or `ogd_margin`.

Contract:

- no replay of old prompts during later rounds;
- no gold-old training;
- no inference memory;
- only low-rank training state `Q` survives across rounds;
- final artifact remains a single dense checkpoint;
- include every trainable parameter in the protected gradient, or freeze parameters not included. Do not let RMSNorm or other non-Linear top-block parameters move outside the projection while claiming answer-level protection.

Basis collection:

- after each stream is committed, use committed-correct facts only;
- include both `p_seen` and `p_para`;
- define the scalar as gold/teacher answer margin against runner-up, or a small top-k logit KL if margin is too noisy;
- collect VJP gradients w.r.t. the trainable top block;
- build a rank-capped QR/SVD basis.

Feasibility warning: a full flattened basis over ~29.8M trainable parameters is memory-heavy. If full OGD is too large, use a blockwise per-parameter-tensor OGD basis, but label it honestly as `block_ogd_margin`, not full OGD. It is still stronger than the current `V_out V_out^T G U_in U_in^T` factorization because the stored directions are actual answer-level gradients.

Run sequence:

```text
pilot:    6 streams x 40 facts, 2 seeds, attr mode
arms:     naive_fixed, nswrite, ogd_head, ours(reference)
decisive: 24 streams x 40 facts if the pilot beats nswrite
```

Use attr mode first because that is where the R36-I ceiling is already mapped. KG mode is useful after the mechanism is established, not for the first diagnostic.

## Numeric gates

Pilot gate to continue to 24 streams:

- `ogd_head all_seen >= nswrite all_seen + 0.05`;
- `ogd_head oldest_S0_forgetting <= nswrite oldest_S0_forgetting - 0.10`;
- newest stream no more than 0.05 below `nswrite`;
- base-hop drop <= 0.03.

Decisive 24-stream interpretation:

- If `all_seen <= nswrite + 0.10` or final all-seen stays below 0.50, C is a negative and the rehearsal-free frontier is closed strongly.
- If all-seen reaches about 0.60-0.65 with oldest forgetting materially reduced, the ceiling claim must be softened: answer-level projection helps, but still does not replace replay.
- If all-seen reaches >= 0.70 and all-para >= 0.55 while newest stays intact, then the R36-I representational-ceiling claim is overturned and we should continue answer-level rehearsal-free work before moving to A.

This keeps C bounded. It gets one honest chance, not an open-ended method search.

## Option A after C

If OGD/GPM also plateaus, move immediately to minimal-footprint rehearsal. That is the practical successor to the current positive result.

I would sweep stored old probes per stream:

```text
K = 0, 1, 2, 4, 8, 16, 40
```

Compare:

- stem replay with stored prompts but no gold-old labels;
- model-self-generated old probes, where the model authors its own old-subject prompts;
- oracle gold-old as upper bound, not as the deployed method.

Pass criteria for a strong constant-memory result:

- K <= 4 or K <= 8 gets within 0.05-0.08 all-seen of full replay;
- all-para remains >= 0.75 on the 6-stream task or degrades smoothly with K;
- oldest forget <= 0.05;
- no inference memory;
- no full historical joint training.

That would be a stronger deployment story than pure rehearsal-free if C fails: small training-time rehearsal is enough to keep writing knowledge into weights.

## Para-gap probe

I would not let the para-dominated oracle gap preempt C. It is already explained by R24/R35: multi-view teacher coverage improves paraphrase transfer, and no-gold self-distill trails gold-old mostly on unseen phrasings.

A targeted probe is still useful later, especially if the capstone emphasizes paraphrase robustness:

```text
R36-EV-MV: add 3-4 relation paraphrase templates per KG relation
bar: oracle para gap +0.131 -> <= +0.07
constraints: seen gap does not worsen, hop drop <= 0.03, no gold-old replay
```

This can also be folded into Option A, because minimal replay footprint and prompt diversity are coupled.

## Bottom line

Do C, but define it narrowly as answer-level OGD/GPM. If it is just another activation-basis projection, skip it. If answer-level OGD also fails the 24-stream gate, then the rehearsal-free boundary is earned rather than assumed, and the next contribution should be minimal-footprint training-time rehearsal into dense weights.

Do not declare growth yet. Nothing in R36-EV or R36-I justifies growth as necessary; growth only comes back if fixed-capacity dense writing hits a measured writable-gradient/newest-learning wall or if a grown/isolated branch gives a compute or retention advantage under matched controls.
