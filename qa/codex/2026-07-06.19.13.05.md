## Required wording fixes

### 1. R35 should not say "near" without the gap

Current row:

> **R35** brackets | **EWC << replay <= gold-old oracle** - replay is near the gold-old upper bound with no gold

I would replace with:

> **R35** brackets | **EWC << replay < gold-old oracle** - replay is far above regularization/no-replay baselines
> (0.890 vs EWC 0.456) but still below the gold-old replay ceiling (oracle gap +0.104 seen / +0.156 para).

This preserves the win without blurring the honest self-distill headroom.

### 2. R36-A "irreducibly O(#facts)" should be narrower

The current sentence is directionally right for independent arbitrary facts, but too theorem-like:

> retention footprint is irreducibly O(#facts)

Better:

> For independent counterfactual facts, this experiment shows random sublinear coverage does not protect
> non-replayed items: retained information has to scale with the number of independent facts being preserved.
> This is an O(#facts) information-footprint result for arbitrary independent facts, not a universal lower bound
> on all structured-data coresets or self-generated coverage schemes.

That matches the evidence: K-subset replay preserves the rehearsed items, not stream-mates. It does not prove every
possible non-random coreset/generative-probe scheme must replay every original prompt at the same frequency.

### 3. "Beats standard CL baselines" is fair, but specify the comparison class

The claim is fair if it is phrased as:

> beats standard **in-weights no-replay** continual-learning baselines in the same sequential harness, including a
> continued-FT baseline that has gold new-stream labels but no old replay.

Avoid phrasing that sounds like "replay beats every possible CL baseline." R35 already shows gold-old replay oracle
is higher; R36-A2 is the deployed cheap-replay version. The clean point is: **without old replay, even gold-new
continued FT forgets; with compact committed replay targets, ours retains without old gold and without inference
memory**.

### 4. Tighten "lifelong" scale language

The capstone uses "lifelong" in the CL sense, which is okay, but the scope section should keep the test horizon visible.
I would add one phrase in the headline or scope:

> lifelong-style 6-stream factual streams at 0.5B scale

This prevents readers from mistaking the result for open-ended deployment evidence.

## Future-work framing

The no-router growth section is strict enough. It correctly bans task ID, key bank, per-stream lookup, and routed
inference; it treats `iso_oracle_route` / `iso_key_route` as upper bounds only; and it requires fixed-capacity and
large-from-start controls plus FLOPs/parameter reporting.

I would keep one extra sentence:

> A routed arm can diagnose whether isolation itself has value, but it is not a project-valid solution unless the
> isolated knowledge can be merged into one un-routed dense path without replay-like historical supervision.

This closes the common loophole where "growth works" quietly means "routing works."

## Bottom-line edit recommendation

The bottom line is basically right. I would change only the last sentence to make the growth status unmistakable:

> Replay-consolidation is the closed positive; first-order rehearsal-free protection and random sublinear replay are
> bounded negatives; growth remains an explicitly unproven future frontier that must win under a strict no-router,
> matched-compute isolation test before it can be claimed as part of the solution.

With those edits, I would close R19-R36. The next research frontier should be named as R37, not appended as a last
minute pre-capstone check:

1. **R37-A:** strict no-router growth isolation, only if the harness can enforce the contract cleanly.
2. **R37-B:** structured/generative replay coverage, if the goal is to reduce O(#facts) prompt storage without losing
   independent-fact retention.
3. **R37-C:** better committed-target/scaffold quality, if the goal is to close the para-dominated oracle gap.

For the project objective, R36-A2 is the strongest deployable endpoint: new knowledge is stored in dense weights,
retention is achieved without inference memory, joint full retraining is avoided, and the remaining replay footprint is
made as cheap as the current evidence allows. Growth should stay in the title of the larger program, but not in the
claim of this capstone.
