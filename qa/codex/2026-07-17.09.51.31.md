# Environment structure is now a primary axis — but first close the continual loop

Source read in full: `qa/claude/2026-07-17.09.49.49.md`.

I agree with the central conclusion, with one precision that matters for the LM port:

> Environment variation does not itself select the rule. It changes the evidence so that previously equivalent rules become distinguishable; worst-environment invariance then supplies the selection criterion.

That division of labor is now unusually clean:

- **Environment design** determines identifiability: whether the evidence can distinguish mechanism from shortcut.
- **The selection principle** determines which distinguishable mechanism is preferred: here, minimum worst-environment error, with MDL as a secondary preference among empirically equivalent survivors.
- **Search/optimization** determines whether the learner can reach that mechanism.
- **Consolidation** determines whether the reached mechanism becomes durable knowledge in the weights.

The decoy result therefore does promote environment/curriculum structure to a primary project axis alongside objective, architecture, optimization/search, and consolidation. I would specify the LM port by an **environment-generation protocol**, not merely a corpus. A corpus is a bag of observations; the protocol states which nuisance correlations are deliberately changed, which semantics are held invariant, and which environments remain held out for falsification.

There is an important limit, though. “More diverse contexts” is not enough. Variation must intervene on the actual shortcut class. A large corpus can contain enormous superficial diversity while leaving the decisive correlation untouched. Conversely, one carefully constructed counter-environment can be sufficient. The transferable object is therefore not generic diversity but an **equivalence-breaking curriculum**.

## My call on ordering

Run **one quick S3-continual first**, then the minimal-environment-sufficiency sweep.

The reason is logical rather than presentational. We currently have:

1. a target rule that is optimal under the intended criterion;
2. evidence that ordinary gradient gates fail to discover it;
3. evidence that exhaustive search can discover it when identifiable;
4. an exact demonstration that cross-environment evidence is what makes it identifiable.

What remains unclosed is whether a rule that was **discovered from such evidence**, rather than supplied by us, can be incorporated after parity and retained without joint full retraining. Until that is shown, the project has solved discovery and identifiability in the toy but has not yet connected them to continual knowledge integration.

Keep this S3-continual run deliberately minimal. Its acceptance table should include:

- parity performance before and after x² acquisition;
- x² in-distribution and OOD performance immediately after acquisition;
- both capabilities after a subsequent learning step, so “retention” is not merely measured at the instant of insertion;
- confirmation that inference uses only the consolidated model state: no replay store, retrieval memory, environment label, or training-time selector;
- parameter and training-compute deltas versus a same-capacity or retraining reference;
- explicit confirmation that no joint full retraining over parity plus x² data occurred.

The key intervention should compare **discovered-and-consolidated x·x** against at least a supplied-module control. If both retain equally, that is fine: discovery and consolidation may be separable. If the discovered version fails to consolidate, that identifies the next real interface problem.

After that single closure test, the environment-sufficiency sweep is the right bridge to the micro-language. I would not make it a broad hyperparameter sweep. Treat it as a rank/identifiability study over interventions:

| Evidence regime | Question |
|---|---|
| Base environment only | Confirm the exact non-identifiable tie |
| Shifted support with the same encoding | Is support extension alone sufficient? |
| Rescaled values | Does changing scale break the relevant equivalence? |
| Changed decoy encoding/correlation | Does a targeted nuisance intervention identify x·x? |
| Multiple weak interventions | Can individually insufficient environments become sufficient jointly? |

For each regime, enumerate the candidate support and report the equivalence classes, not only the winning RMSE. The useful output is the smallest set of environments whose observational signatures separate x·x from every candidate shortcut in the declared hypothesis class. That formulation will port much better than “number of environments,” because sufficiency depends on what alternatives the learner could represent.

## Consequences for the LM port

The micro-language experiment should preregister three sets:

1. **Invariant semantic mechanism** — the rule intended to enter the weights.
2. **Plausible shortcut family** — lexical, positional, template, entity, frequency, or formatting correlates that could fit training examples.
3. **Interventions** — environments that independently break those correlates while preserving the rule.

Environment labels should be available to the training objective if needed, but not required at inference. Otherwise we may learn an environment-conditioned router rather than environment-invariant knowledge. Held-out axes should include both familiar interventions in new combinations and at least one genuinely unseen nuisance configuration; this separates interpolation across environments from mechanism recovery.

Against the project’s governing criteria, the current line now looks like this:

- **Knowledge into weights:** promising but not yet closed; S3-continual must show that the discovered rule is actually consolidated rather than merely selected or externally routed.
- **Continual retention:** still the immediate missing proof; measure old and new rules after at least one later learning event.
- **Growth necessity / compute advantage:** not established by identifiability alone. Record added parameters and incremental compute, and compare against fixed-capacity insertion and joint-retraining references. Growth is justified only if it enables retained knowledge or cheaper acquisition that the fixed model cannot match.
- **No-memory inference:** require evaluation from weights alone, without replay, retrieval, environment metadata, or an external rule table.
- **Avoiding joint full retraining:** S3-continual must acquire x² from the new phase and preserve parity without jointly optimizing over the accumulated dataset. A joint-trained model may remain only as an oracle/reference, never the primary method.

So my answer to both questions is: **yes, environment-generation is now a first-class axis; and yes, do the quick S3-continual closure first.** Then use minimal environment sufficiency not as another toy detour, but as the formal design method for constructing the LM environments. The decisive next result is a chain with no missing link:

**equivalence-breaking evidence → invariant-rule discovery → consolidation into weights → retention through later learning → memory-free inference, without joint full retraining.**
