# The decomposition is real; the headline needs one more cut

Source read in full: `qa/claude/2026-07-17.04.06.51.md`.

The B-only control resolves the largest ambiguity in the zero-referee result. The monotone exchange
between B-only reconstruction and the A→B advantage is unusually clean, and the k=4–16 region makes
it difficult to dismiss as merely the k=1 class-balance artifact. This is now a useful causal
decomposition of old-task accuracy.

I would, however, stop one step short of the headline **“rule-discovery ⊕ memorization.”** What the
second term identifies is the causal value of entering B training with an A-trained weight state:

\[
P_S = \operatorname{Acc}_{A\to B}(S)-\operatorname{Acc}_{B\text{-only}}(S).
\]

That is definitely persistent information in the learning trajectory, but it may contain at least
three things: a reusable rule representation learned from A, a better optimization basin, and
pair-specific memorization. The present control does not distinguish those. So the strongest fully
licensed statement is:

> Old-task competence decomposes into reconstruction from later experience, retained
> path-dependent weight state, and lost old competence; compressibility controls their mixture.

This is stronger and more precise than the original forgetting-only framing without assigning all
of the retained term to memorization prematurely.

For any evaluation subset \(S\), I would use the A-only score explicitly:

\[
R_S=\operatorname{Acc}_{B\text{-only}}(S),\quad
P_S=\operatorname{Acc}_{A\to B}(S)-R_S,\quad
L_S=\operatorname{Acc}_{A\text{-only}}(S)-\operatorname{Acc}_{A\to B}(S).
\]

Then \(R_S+P_S+L_S=\operatorname{Acc}_{A\text{-only}}(S)\). In the current sweep the A-only ceiling
is 1, so the reported identity is exact. In the rule-plus-exceptions experiment, especially at high
ρ, A-only may no longer be perfect; forcing the three terms to sum to 1 would silently count
never-learned examples as forgetting. Report `unlearned = 1 - A-only` separately if needed.

## Selector answer

Use raw frozen descriptor coverage as the primary selector, and hidden-activation coverage as a
separately classified secondary arm.

The raw `[x_e; x_r]` arm is the clean falsification because it has no route to the random exception
mask. Normalize the entity and relation blocks separately, fix the distance metric in advance, and
use a deterministic coverage rule such as greedy k-center with seed-fixed tie breaking. Its expected
exception enrichment should equal stratified random selection.

The hidden-activation arm answers a different question: whether the A learner's representation has
already made exception identity geometrically accessible. It is not merely a stronger version of
input coverage. If it protects exceptions, that is **not automatically leakage**—the A teacher may
have encoded the exceptional pairs in its weights. Audit it by measuring exception enrichment and,
ideally, a held-out probe for exception-mask predictability from hidden activations. Call this arm
`representation-conditioned coverage`, and account for its need to read the A snapshot during
selection. It can still satisfy no-memory inference if that snapshot is absent at inference, but its
selection-time storage and compute are real costs.

Likewise, “raw coverage protects some exceptions” is not by itself a leakage proof. A random mask
implies no expected descriptor enrichment, but finite-sample variation and more uniform rehearsal
geometry can change interference. Treat systematic exception enrichment or performance beyond
paired-random confidence intervals as an audit trigger, not as an automatic conviction.

I would order the selectors conceptually as:

1. Stratified random: legal baseline.
2. Raw-descriptor coverage: legal, structure-only selection.
3. Representation-conditioned coverage: legal if model access at selection is allowed, but a richer
   information channel whose cost must be reported.
4. Provisional-interference selector: illegal diagnostic for the best update-aware frontier.
5. Exception oracle: illegal diagnostic for the best storage-allocation frontier.

## One addition that would complete the semantic decomposition

Add an unseen rule probe: fresh A-domain pairs generated by the same base rule but never presented
during A training. It need not consume referee budget. The three relevant causal advantages then
have distinct meanings:

- A→B advantage on unseen rule pairs: retained reusable rule/representation state.
- A→B advantage on seen rule-following pairs beyond the unseen probe: possible instance-specific
  state or train-distribution effects.
- A→B advantage on random exception-out pairs: the cleanest evidence of retained atomic memory in
  weights.

Without this probe, the five-way report is excellent for locating failures but cannot quite justify
calling the whole retained term memorization. With it, “rule-discovery ⊕ memorization” becomes a
testable decomposition rather than a label.

For the planned sweep, keep masks, initializations, B order, optimizer steps, and evaluation items
paired across A→B and B-only. Report absolute accuracies plus \(R,P,L\) for every nonempty split;
exception coverage is `N/A`, not zero, when ρ=0. Confidence intervals on selector differences and
actual selected-exception enrichment will be more informative than only averages over three seeds.

## What would count toward the project goal

- **Knowledge into weights:** retained performance with the referee removed at inference is genuine
  weight-carried state. Random exceptions demonstrate storage, not useful knowledge; unseen-rule
  generalization demonstrates internalized structure.
- **Continual retention:** the rule/exception split and the B-only control now identify where old
  competence comes from rather than treating all A accuracy as retention.
- **Growth necessity:** pure random exceptions can establish an irreducible storage frontier but
  cannot motivate growth. The second-low-rank-rule intervention must show that expansion converts a
  structured residual into unseen-pair generalization when fixed capacity cannot.
- **Compute advantage:** compare fixed and expanded models at matched stream-training FLOPs, report
  persistent parameters and referee bytes, and include inference cost. Growth is justified only if
  it improves the retention/generalization frontier, not merely because it spends more capacity.
- **No-memory inference:** run the final evaluation with no retrieval, referee, teacher, or selector
  available. Training-time exemplars should be reported as a separate persistent-memory cost.
- **No joint full retraining:** keep full A unavailable during B updates. A joint run may appear only
  as a diagnostic ceiling, never as the mechanism producing the main result.

The most useful decision table after the sweep is simple. If raw coverage helps rule-following pairs
but not exception-out pairs, the compressibility thesis survives. If the exception oracle succeeds
while legal selectors fail, the bottleneck is selection. If even the oracle fails, the bottleneck is
update dynamics or capacity. If expansion later helps only the second structured rule—and improves
unseen-pair generalization under a declared compute/storage budget—then there is finally evidence
for growth as a necessary continual-learning operation rather than as a larger memorizer.
