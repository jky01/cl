# h=128 成立；先做 penalty，但把「path wall」的判準再收緊

已完整讀取來源：`qa/claude/2026-07-16.21.39.49.md`。

這個修正很重要。`h=64` 應正式降格為容量不足的反例，不能再用來主張 continual interference；`h=128` 才是目前最乾淨的主實驗點。此處 joint optimizer 實際找到 `acc(A∪B)=1.0`，已提供一個存在性 witness，而 naive sequential 的 `Apost=0.082` 則顯示：即使固定共享權重有足夠表達能力，普通更新路徑仍幾乎完全摧毀舊知識。

我同意先做 **(a) A-logit preservation penalty**，暫時不要直接上 Jacobian null-space projection。原因不是 projection 不重要，而是 penalty sweep 能先回答更基本的問題：在不增加 inference-time slots、且 oracle 提供完整 A 行為的最有利條件下，是否存在一段實際可優化的折疊路徑？若連這個上界都失敗，projection 才有明確的診斷價值；若 penalty 已成功，projection 的任務則變成降低所需舊資料／舊行為資訊，而不是再證明可折疊性。

不過，我會收緊目前的推論語言：

- `joint=1.0` 證明的是存在一組可表示 A∪B 的共享參數，不證明從目前 A solution 到該解存在一條低損失、低遺忘的連續路徑。
- fresh-init fold 成功而 A-init fold 失敗，證明的是在**相同 objective、budget 與 optimizer family 下的 initialization-dependent accessibility**。它強烈支持 path dependence，但尚不能區分真正的拓撲／幾何障礙、optimizer failure、或 A-logit constraint 與 joint label objective 的不等價。
- fresh-init fold 也失敗，不能直接推成 representational failure，因為 joint witness 已否定「整個模型類無法表示」；更可能是 fold objective 過度約束、teacher target 不相容，或搜尋仍未找到 witness。

因此 fold round 最好至少同時保留四條線，而不只是兩條：

1. **A-init + A labels + B labels**：full-data rehearsal oracle。這是最直接的路徑可達性上界。
2. **fresh-init + A labels + B labels**：重現 joint witness，確認本輪 seed／budget 下基準仍成立。
3. **A-init + A-logit preservation + B teacher**：真正要測的 fold path。
4. **fresh-init + A-logit preservation + B teacher**：分離 initialization 與 fold objective。

這個 2×2 能避免把「初始化問題」和「蒸餾目標問題」混為一談。每條線都應使用相同的 restart 數、更新步數與最佳模型選擇規則；否則 fresh-init 與 A-init 的差異可能只是搜尋資源差異。

Pareto 報告除了 `accA/accB`，我建議再記三個量：A logit drift、A minimum-margin drift、以及 fold 前後相對於 A solution 的參數距離。若分類準確率維持但 margin 大幅塌縮，那不是可靠 retention，只是尚未越過 decision boundary。反過來，如果 logits 無法精確保存但 margins 與 accA 都穩定，則 exact-logit penalty 可能比「保留知識」實際需要的條件更強，會人為壓縮可行 Pareto frontier。

還有一個關鍵控制：保存 joint=1.0 的那個 shared witness，直接量測它在 A teacher logits 下的 penalty。若 joint witness 對 A labels 完美，卻與 A-only teacher logits 差異很大，那麼「joint 可表示」並不保證「exact A logits + B 可同時滿足」。這會立即告訴我們 fold 卡住的是 teacher-function compatibility，而不是容量或路徑。

對 null-space projection，我的立場是把它放在 penalty 結果之後，並視為**局部、需反覆重線性化的近似**。`J_old Δθ≈0` 只約束當前鄰域；大步移動後原 Jacobian 的 null space 不再可靠。若要做，至少應比較：

- 固定初始 projector；
- 週期性重估 projector；
- 只保留 top singular directions 的低秩近似；
- projection 後的 B-gradient retained norm，以及每步實際 A-logit drift。

如果 projected gradient norm 很快接近零，這本身就是有價值的結果：在目前 A solution 的局部幾何中，新知識方向與舊行為敏感子空間高度重疊，growth 可能不是工程選項，而是逃離局部干擾所必需的自由度。反之，若存在大量 null-space gradient 卻仍無法完成 fold，問題比較可能在曲率、長程路徑或 optimizer。

就總路線而言，這一輪的角色應明確限定為 **oracle consolidation geometry**，不是 continual-learning solution。它確實測試 knowledge-into-weights：成功標準是 private slots 真正刪除，A/B 都由同一 folded checkpoint 的共享權重產生；也滿足 no-memory inference。但 full-A constraint 仍依賴完整舊資料，因此不滿足 deployable continual learning，更不能成為 joint full retraining 的替代說辭。下一輪 full → bounded → zero 的 referee sweep 才會揭示方法是否有實際 continual retention 能力。

最後，參數匹配 growth control 不應只問「加寬是否提高最終準確率」，而要問相同新增參數與相同訓練 compute 下：

- private growth 能否用局部更新快速吸收 B；
- fold 能否把 B 轉入既有共享權重並刪除 growth；
- 累積多輪後是否必須永久成長；
- 相對等寬 shared model，是否以更少舊資料與更新 compute 保住 A。

我的具體決策是：**在 h=128 先跑 penalty-based 2×2 fold，保留完整 Pareto 與 joint-witness compatibility 檢查；只有結果顯示 A-init 的可達性是主要瓶頸時，再建 Jacobian projection。** 這比立刻實作 projection 更能把 capacity、objective mismatch、initialization dependence 與真正的 fold geometry 分開。
