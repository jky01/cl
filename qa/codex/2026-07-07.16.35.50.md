## What Looks Right

The new instrumentation captures the right causal surface:

- Stable per-QA ids are assigned before training (`seed:t:art:q`), with stream index and article title.
- Frozen-base answer-sequence bits use the same answer-token masking as `qa_ce`, including the answer stop
  token. This is the right multi-token analogue of the R40 KG surprise probe.
- Base closed-book EM is logged separately for original and paraphrased prompts, and answer token count is
  available, so offline analysis can separate total bits from answer-length confounding.
- Per-arm final retention is keyed back to qid with `final_eval_em`, `final_orig_em`, `replayed`, and
  `commit_t`.
- The summary focuses on **old-only, non-replayed** committed items, which preserves the R38B lesson and
  avoids the fresh-stream accounting artifact.
- `compact_cpt_qa`, `k1`, `k0`, and `k0_noanchor` are the right arms: full replay is the ceiling/control,
  `k1` is a small residual-budget slope point, and `k0`/`k0_noanchor` expose the no-replay floor.

This advances the project objective because it tests when knowledge can be internalized into weights with no
inference memory and no joint full retraining, and whether the residual replay/write cost is better predicted
by prior anchoring / surprise than by raw fact count.

## Guardrails

1. **Key cross-source rows by `(source, seed, qid)`, not `qid` alone.** The same qid string can exist in both
   `squad` and `synth`, but it refers to different examples.

2. **If actual stream counts differ across seeds, distrust the built-in `surprise_summary`.** It uses the
   global `ACTUAL_STREAMS` from the latest processed seed. For the offline sidecar analysis, compute
   `final_t` per `(source, seed)` from the rows and filter `commit_t < final_t`.

3. **Control answer length explicitly.** Use both total base bits and `bits/token = base_bits_para / ans_ntok`.
   A source gap that vanishes after answer-length control is not a surprise-cost result.

4. **Do not pool anchor and no-anchor arms.** Prior R38B showed the neutral base anchor can hurt old-fact
   retention. Treat `k0` and `k0_noanchor` as separate mechanisms.

5. **Use full replay only as a ceiling / learnability control.** The cross-source gap should narrow under full
   replay if the deficit is retention/write budget. But full replay is not the project-valid endpoint because
   it remains per-item rehearsal.

6. **Unique templates are appendix-level unless the smoke is ambiguous.** Since `shared_templates` already
   collapsed in R38B-A, it is sufficient for the main source-effect test. Run `unique_templates` only if
   `shared_templates` produces a confusing result or if you need a robustness appendix.
