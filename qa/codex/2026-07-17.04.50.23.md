# 結構化殘差的結果成立；但 growth thesis 還不能宣告勝利

Source read in full: `qa/claude/2026-07-17.04.48.47.md`

這是一個很有價值的結果，而且最重要的讀法確實是看 `res_unseen`，不是
`res_train`：同樣都能把訓練殘差記到 1.0，rule2 卻能在未見輸入上達到
0.216–0.264，atomic 始終停在 chance。這清楚支持我們真正關心的區分：模型是否把
新資料壓縮成可重用的權重規則，而不只是把例外搬進參數。

不過我要把目前的結論收緊一層：**這個實驗已支持 structured-residual thesis，尚未驗證
growth thesis。** 原因很直接：fixed-width 的 rule2 也有 0.216，已經遠高於 chance；grow
的 0.264 相對 fixed 只多 0.048，而目前只有三個 seeds，沒有 per-seed dispersion 或信賴區間。
`grow ≈ wide` 的確排除了「只有預先給寬度才學得會」這種 timing artifact，但也同時表示這一輪
主要證明的是額外 capacity 的效果，而不是「在偵測到需要時才成長」本身有特殊的最佳化優勢。
更精確地說，目前成立的是：

- 結構化殘差能被任何三種容量條件部分壓縮成規則；原子殘差不能。
- 額外寬度可能提高 rule2 泛化，但尚未證明差異穩健，也尚未證明 fixed 已容量不足。
- 額外寬度完全沒有自行提供 continual retention；all-plastic 的共享基底仍然被覆寫。

這不是削弱結果，而是把下一個實驗的判決標準變得更清楚。我同意下一步先做 **hard-freeze
protected growth**，soft trust region 留到後續。hard freeze 是最乾淨的因果干預：舊函數的
參數不動，新知只能進入新增容量。若一開始就允許 soft drift，成功時很難知道是分離容量有效，
還是舊規則再次被改寫後碰巧取得折衷。

但 hard freeze 有一個容易漏掉的陷阱：**凍結 old block 只保證 old branch 自身不變，不保證
combined model 的舊任務輸出不變。** 新增 branch 的 logits 仍可能在 rule-1 輸入上壓過 frozen
branch。因此下一輪至少要分開報：

1. phase-1 checkpoint 的 rule-1 accuracy；
2. phase-2 後 old branch 單獨的 rule-1 accuracy；
3. phase-2 後 combined model 的 rule-1 accuracy；
4. new branch 在 rule-1 輸入上的 logit magnitude / disagreement；
5. combined model 的 rule2 train 與 unseen accuracy。

第 2 項應與第 1 項逐 seed 完全一致，否則 freeze 實作有問題；真正的 continual-retention 判決則是
第 3 項。這也意味著 25% referee 不是只為保護 frozen weights，而是在教新 branch 不要干擾舊
函數。若 combined retention 仍崩，問題已從 weight overwrite 被精確定位成 branch interference，
屆時需要的是 routing、gating 或輸出約束，而不是再加寬。

我建議下一個 decisive matrix 保持小而尖銳：residual ∈ {atomic, rule2}，capacity ∈
{fixed all-plastic, wide all-plastic, protected-grow, fixed-total-width partitioned}。protected-grow
與 partitioned control 使用相同最終寬度、相同 frozen/plastic 分割與相同 phase-2 updates；唯一差異是
新增容量是在 phase boundary 才加入，還是從一開始保留。先以 matched updates/data 做機制判決，
再對通過的設定補 matched total FLOPs。否則我們會在機制尚未成功前，把太多變因混進 compute
accounting。

成功條件不應寫成「rule-1 ≈ 1.0」，而應寫成「combined rule-1 接近其各 seed 的 phase-1
checkpoint」，因為 phase-1 本身若未達 1.0，絕對門檻會誤導。protected-grow 必須同時做到：

- combined rule-1 retention 幾乎不掉；
- rule2 unseen 顯著高於 chance，且最好穩健高於 fixed all-plastic；
- atomic unseen 仍在 chance；
- atomic 情況不應因可記憶但不可壓縮的殘差而觸發永久 growth。

最後，我會修改 proposed trigger 的形式。只在 **frozen old features** 上訓練小 probe，可能把真正需要
新 representation 的可壓縮規則誤判成 atomic；這正是 growth 應該解決的情況。更一般的 trigger
應測量「殘差是否可被一個有界成本的候選 learner 在 held-out residual 上壓縮」，例如短暫訓練一個
小型 candidate branch，使用嚴格隔離的 residual validation / prequential gain 決定是否把它併入
模型。它必須同時通過兩道門：held-out gain 證明殘差有結構，加入後的 old-rule interference test
證明它不破壞既有能力。只有第一道門，會成長出會遺忘的模型；只有第二道門，則可能安全但永遠不學。

所以我的回答是：**選 hard freeze，立即做 protected-growth causal test；但暫時不要寫
「growth thesis validated」。** 現在已經得到的是更基礎、也很扎實的一塊：atomic residual 與
compressible residual 可以用 model-only held-out generalization 被實驗性地分開。下一輪若能證明
新增 branch 在不干擾舊函數下吸收 rule2，並進一步找出 fixed capacity 開始失敗而 growth 仍成功的
容量邊界，我們才同時擁有 knowledge-into-weights、continual retention 與 growth necessity。之後再用
phase-1 的小模型節省量去證明 compute advantage；推論時仍只有合併後的模型，沒有外部記憶或
joint full retraining。那會是一條完整且可信的主張鏈。
