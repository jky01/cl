下面我把它降到 **可以實作成 PyTorch / JAX module 的 State Spec 層級**。

重點先說：

> 若要「全神經網路化」並且讓
> [
> \mathcal{S}_{t+1}
> =================
>
> g\mathcal{S}_{candidate}
> +
> (1-g)\mathcal{S}_t
> ]
> 這類 commit interpolation 成立，**所有 state 都必須是固定形狀、連續值張量**。
> 因此 memory 不能是真正動態長度 list，version id 不能是不可微整數 pointer，rollback 也不能只靠外部 checkpoint。
> 要改成：**固定槽位 + allocation gate + soft version embedding + low-rank delta trace**。

下面是一個完整設計。

---


其中：

# 2. 核心原則：State 必須固定形狀

完整 state：

```text
State S_t = {
    mem_slots,
    expert_latents,
    expert_meta,
    core_delta_latents,
    core_delta_gates,
    core_stats,
    router_contexts,
    router_expert_bias,
    router_memory_bias,
    router_temperature,
    importance_core,
    importance_memory,
    importance_expert,
    plasticity_core,
    plasticity_memory,
    plasticity_expert,
    teacher_sketch,
    sentinel_probes,
    rollback_trace
}
```

所有 state 都是 tensor。

在 meta-training 時，每個 episode 可以有 batch dimension：

```text
B = meta batch size
```

所以所有 tensor 通常長這樣：

```text
[B, ...]
```

部署時可以視為：

```text
B = 1
```

# 3. Memory Slot State Spec

## 3.1 記憶庫形狀

記憶庫是固定槽位：

[
M_t \in \mathbb{R}^{B \times N_{mem} \times d_{slot}}
]

具體：

```text
mem_slots: [B, 4096, 800]
```

**不使用動態 append list。**

原因是：

[
S_{t+1}
=======

gS_{candidate}
+
(1-g)S_t
]

要求：

[
shape(S_{candidate}) = shape(S_t)
]

所以記憶庫必須固定長度。

---

## 3.2 Memory slot 精確 layout

每個 memory slot：

[
m_i \in \mathbb{R}^{800}
]

layout：

| 區段                  |  維度 | 範圍        | 說明                        |
| ------------------- | --: | --------- | ------------------------- |
| key (k_i)           | 128 | `0:128`   | 檢索 key                    |
| value (v_i)         | 512 | `128:640` | 記憶內容 / latent knowledge   |
| context (u_i)       |  64 | `640:704` | 適用情境                      |
| source (s_i)        |  32 | `704:736` | 來源 / provenance embedding |
| time (t_i)          |  16 | `736:752` | 時間 / freshness embedding  |
| version (z_i^{ver}) |  32 | `752:784` | 版本群組 embedding            |
| aux (a_i)           |  16 | `784:800` | scalar control fields     |

所以：

[
d_{slot}
========

# 128 + 512 + 64 + 32 + 16 + 32 + 16

800
]

---

## 3.3 Aux scalar layout

`aux` 是 16 維連續 scalar：

| index | 名稱                | 說明       |
| ----: | ----------------- | -------- |
|     0 | `alloc_logit`     | 此槽位是否被使用 |
|     1 | `confidence`      | 記憶可信度    |
|     2 | `reliability`     | 來源可靠性    |
|     3 | `usage_ema`       | 使用率 EMA  |
|     4 | `read_count`      | 正規化讀取次數  |
|     5 | `write_count`     | 正規化寫入次數  |
|     6 | `age`             | 記憶年齡     |
|     7 | `freshness`       | 新鮮度      |
|     8 | `plasticity`      | 此槽位可塑性   |
|     9 | `stability`       | 穩定性      |
|    10 | `conflict_score`  | 衝突分數     |
|    11 | `safety_risk`     | 安全風險     |
|    12 | `protected_gate`  | 是否受保護    |
|    13 | `inhibit_logit`   | 抑制程度     |
|    14 | `merge_score`     | 合併候選分數   |
|    15 | `tombstone_logit` | 軟刪除標記    |

注意：這些都不是 hard bool，而是連續值。

例如：

[
allocated_i = \sigma(aux_i[0])
]

[
inhibited_i = \sigma(aux_i[13])
]

[
tombstone_i = \sigma(aux_i[15])
]

# 4. Memory Read 介面

## 4.1 輸入

Transformer hidden state：

[
H \in \mathbb{R}^{B \times T \times d_{model}}
]

例如：

```text
H: [B, T, 1024]
```

產生 memory query：

[
Q_m = W_q H
]

```text
Q_m: [B, T, 128]
```

---

## 4.2 取出 slot 欄位

```text
K_mem   = mem_slots[:, :, 0:128]      # [B, N_mem, 128]
V_mem   = mem_slots[:, :, 128:640]    # [B, N_mem, 512]
CTX_mem = mem_slots[:, :, 640:704]    # [B, N_mem, 64]
SRC_mem = mem_slots[:, :, 704:736]    # [B, N_mem, 32]
TIME    = mem_slots[:, :, 736:752]    # [B, N_mem, 16]
VER     = mem_slots[:, :, 752:784]    # [B, N_mem, 32]
AUX     = mem_slots[:, :, 784:800]    # [B, N_mem, 16]
```

---

## 4.3 讀取分數

基礎相似度：

[
score_{b,t,i}
=============

\frac{
Q_{b,t} \cdot K_{b,i}
}{
\sqrt{d_k}
}
]

再加入 gate：

[
allocated_i = \sigma(aux_i[0])
]

[
confidence_i = \sigma(aux_i[1])
]

[
freshness_i = \sigma(aux_i[7])
]

[
inhibit_i = \sigma(aux_i[13])
]

[
tombstone_i = \sigma(aux_i[15])
]

完整讀取分數：

[
score'_{b,t,i}
==============

score_{b,t,i}
+
\alpha confidence_i
+
\beta freshness_i
+
\gamma allocated_i
------------------

## \delta inhibit_i

\eta tombstone_i
]

讀取權重：

[
A_{read}
========

softmax_i(score')
]

```text
A_read: [B, T, N_mem]
```

讀取結果：

[
R_m
===

A_{read} V_{mem}
]

```text
R_m: [B, T, 512]
```

再投影回 model dimension：

[
R_h = W_r R_m
]

```text
R_h: [B, T, 1024]
```

# 5. Memory Write 介面

## 5.1 寫入候選

由目前 hidden state、target、feedback、controller state 產生候選記憶：

[
\tilde{m}
=========

WriteCandidateNet_\Omega(
h,
y,
feedback,
z_{state}
)
]

```text
m_candidate: [B, H_write, 800]
```

其中：

```text
H_write = 寫入 head 數，例如 4
```

所以：

```text
m_candidate: [B, 4, 800]
```

---

## 5.2 寫入權重

對每個寫入 head 產生對所有 memory slots 的 soft write distribution：

[
W_{write}
=========

WriteAddressNet_\Omega(
m_{candidate},
M_t,
z_{state}
)
]

```text
W_write: [B, H_write, N_mem]
```

每個 head 對 slot 做 softmax：

[
\sum_i W_{write}[b,h,i] = 1
]

---

## 5.3 寫入更新

對每個 slot：

[
M_{candidate}[i]
================

(1-\bar{w}*i)M_t[i]
+
\sum_h W*{write}[h,i]\tilde{m}_h
]

其中：

[
\bar{w}_i
=========

\sum_h W_{write}[h,i]
]

實作上：

```text
M_candidate: [B, N_mem, 800]
```

最後用 commit gate 決定是否採用：

[
M_{t+1}
=======

M_t
+
g_M
\odot
(M_{candidate} - M_t)
]

其中：

```text
g_M: [B, N_mem, 1]
```

也可以用全域 gate：

```text
g_M: [B, 1, 1]
```

---

# 6. Memory 固定槽位 vs 可成長

## 6.1 為什麼預設固定槽位

如果記憶庫可成長：

```text
M_t: [N_t, d_slot]
M_{t+1}: [N_t + 1, d_slot]
```

則：

[
gM_{candidate} + (1-g)M_t
]

不成立，因為 shape 不同。

所以全神經、可微分、可 commit-interpolation 的版本應該使用：

```text
固定 N_mem 槽位 + allocation gate
```

也就是：

```text
空槽位不是不存在，而是 allocated ≈ 0。
```

---

## 6.2 如果真的要可成長

可以使用 page bank：

```text
num_pages = P
slots_per_page = N_page
```

例如：

```text
P = 8
N_page = 4096
```

總形狀仍固定：

```text
memory_pages: [B, 8, 4096, 800]
```

只是部分 page 的 `page_alloc_gate ≈ 0`。

這樣表面上可成長，但張量形狀仍固定。

# 7. Expert / Adapter State Spec

## 7.1 不直接存所有 LoRA 矩陣

若直接存每個 expert 在每層每個 projection 的 LoRA：

[
\Delta W_{l,g,e}
================

B_{l,g,e}A_{l,g,e}
]

會非常大。

全神經化版本建議使用：

```text
expert latent + HyperLoRA generator
```

也就是每個 expert 只存一個 latent vector。

---

## 7.2 Expert state

```text
expert_latents: [B, K_exp, d_exp]
expert_meta:    [B, K_exp, d_meta]
```

具體：

```text
expert_latents: [B, 64, 128]
expert_meta:    [B, 64, 32]
```

---

## 7.3 expert_meta layout

`expert_meta` 32 維可以這樣切：

| 區段          | 維度 | 說明              |
| ----------- | -: | --------------- |
| usage stats |  8 | 使用率、最近使用、啟用次數   |
| confidence  |  4 | expert 可信度      |
| plasticity  |  4 | expert 可塑性      |
| stability   |  4 | expert 穩定性      |
| conflict    |  4 | 與其他 expert 干擾   |
| safety      |  4 | 安全風險            |
| capacity    |  4 | 壓縮 / pruning 分數 |

---

## 7.4 HyperLoRA 介面

對每個 expert (e)、layer (l)、module group (g)，產生低秩權重。

輸入：

```text
expert_latent_e: [B, 128]
layer_embed_l:   [64]
group_embed_g:   [32]
```

拼接後：

```text
z_lge: [B, 224]
```

HyperLoRA 輸出：

[
A_{l,g,e}, B_{l,g,e}
====================

HyperLoRA_\Omega(z_{l,g,e})
]

假設 LoRA rank：

```text
r = 8
```

若 module weight 形狀為：

[
W_{l,g} \in \mathbb{R}^{d_{out} \times d_{in}}
]

則：

```text
A_lge: [B, r, d_in]
B_lge: [B, d_out, r]
```

LoRA 更新：

[
\Delta W_{l,g,e}
================

B_{l,g,e}A_{l,g,e}
]

expert 輸出：

[
E_e(h)
======

\Delta W_{l,g,e}h
]

---

## 7.5 Expert routing

Router 輸出：

```text
expert_logits: [B, T, K_exp]
expert_alpha:  [B, T, K_exp]
```

可用 soft top-k 或 Gumbel-softmax：

[
\alpha
======

GumbelSoftmax(logits, \tau)
]

expert 加權輸出：

[
h'
==

h
+
\sum_e
\alpha_e
E_e(h)
]

# 8. Core Model State Spec

## 8.1 不讓 Ω 直接讀完整 (\theta_c)

核心模型權重：

[
\theta_c
]

很大，不適合直接作為 SleepNet 的輸入。

所以分成兩層：

```text
1. base core weights θ_0
   大部分時間固定。

2. core_delta_state
   可被 SleepNet 調控的低秩核心增量。
```

有效核心：

[
\theta_{eff}
============

\theta_0
+
\Delta \theta_{core}
]

---

## 8.2 Core delta state

對每層、每個 module group、每個 delta slot，存一個 latent：

```text
core_delta_latents: [B, L, G, B_core, d_delta]
core_delta_gates:   [B, L, G, B_core, 1]
```

具體：

```text
core_delta_latents: [B, 24, 6, 4, 128]
core_delta_gates:   [B, 24, 6, 4, 1]
```

---

## 8.3 Core delta 轉成低秩權重

由 HyperCoreDeltaNet 產生：

[
A_{l,g,b}^{core},
B_{l,g,b}^{core}
================

HyperCoreDeltaNet_\Omega(
z_{l,g,b}^{core}
)
]

低秩更新：

[
\Delta W_{l,g}^{core}
=====================

\sum_{b=1}^{B_{core}}
\sigma(g_{l,g,b})
B_{l,g,b}^{core}
A_{l,g,b}^{core}
]

有效權重：

[
W_{l,g}^{eff}
=============

W_{l,g}^{0}
+
\Delta W_{l,g}^{core}
]

---

## 8.4 Core stats

SleepNet 還需要知道核心各層狀態，但不讀 raw weight。
使用 core stats：

```text
core_stats: [B, L, G, d_stat]
```

具體：

```text
core_stats: [B, 24, 6, 64]
```

每個 `core_stats[l,g]` 包含：

| 類型                   | 說明                     |
| -------------------- | ---------------------- |
| activation mean      | 該模組 activation 均值      |
| activation var       | activation 方差          |
| grad norm            | 梯度大小                   |
| update norm          | 最近更新大小                 |
| replay sensitivity   | replay 對該模組敏感度         |
| sentinel sensitivity | 哨兵測試敏感度                |
| importance summary   | 重要性摘要                  |
| plasticity summary   | 可塑性摘要                  |
| drift score          | 與 teacher / shadow 的偏移 |

---

## 8.5 (\theta_c) 的編碼方式

Ω 不直接吃：

```text
θ_c: huge tensor
```

而是吃：

```text
core_tokens: [B, L * G, d_z]
```

產生方式：

[
z_{core}^{l,g}
==============

CoreStateEncoder(
core_stats_{l,g},
core_delta_summary_{l,g},
param_sketch_{l,g}
)
]

其中：

```text
param_sketch: [L, G, 64]
```

`param_sketch` 是核心權重的低維摘要，例如：

```text
mean(W)
std(W)
norm(W)
spectral estimate
random projection ΠW
random projection WΠ
```

所以：

```text
core_tokens: [B, 144, 256]
```

因為：

[
24 \times 6 = 144
]

[

\alpha
\Delta S_{trace}
]

[
\alpha
======

RollbackNet_\Omega(
risk,
trace,
verifier
)
]

然後：

[
S_{rollback}

]

## 15.1 Memory tokens

Z_{mem}

]


---

# 21. 訓練 Ω 時的 State Batch

Meta-training 中，一個 batch 是多條「模型生命軌跡」。

```text
B = number of episodes
```

每條 episode 有自己的 state：

```text
S_t[b]
```

但是 Ω 的參數共享：

```text
Ω shared across B episodes
```

所以：

```text

```

不是表示一個模型有 B 份 memory，而是訓練時有 B 個模擬中的模型狀態。

# 24. 最核心的合約

最終，全系統的合約是：

```text
State S_t:
    一組固定形狀、連續值、可插值的張量。

Ω:
    一組神經網路，讀取 S_t 的 encoded tokens，
    輸出 S_candidate 以及各種 commit gates。

Commit:
    S_{t+1} = S_t + g ⊙ (S_candidate - S_t)

Memory:
    固定槽位，不 append；
    用 alloc / inhibit / tombstone / keep gate 模擬新增、抑制、刪除。

Core:
    不直接讓 Ω 操作完整 θ_c；
    用 core_delta_latents + HyperCoreDeltaNet 表示可塑核心更新。

Adapter:
    不直接手工插拔；
    用 expert_latents + HyperLoRA 表示可生成 adapter。

Router:
    用 context prototypes、bias、temperature、usage matrix 作為可調 state。

Rollback:
    不靠外部 checkpoint；
    用 rollback_trace + inverse delta latent 做 soft rollback。
```

一句話：

> **全神經網路化的關鍵不是把所有東西都寫成符號，而是把每一個「可變部分」都轉成固定形狀、連續、可插值、可被 encoder 讀取、可被 gate 修改的張量。這樣 SleepNet(_\Omega) 才真的能被定義、訓練與反向傳播。**
