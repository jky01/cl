1. 核心突破命題

你現在專案比較接近：

externalize / isolate 知識，避免 shared-weight interference。

如果要升級成真正突破，命題要改成：

Grow-and-Consolidate：小模型先以 function-preserving 方式長大，新的容量一開始不破壞舊功能；接著把新知識、新能力、外部記憶與分支能力逐步壓縮回單一 dense 權重，使最終模型本體變大且變聰明。

11. 技術難點與解法
難點一：長大後不一定更聰明

更大模型本身不保證更好。Scaling laws 顯示 loss 與模型大小、資料量、compute 大致呈 power-law 關係，但 Chinchilla 後的結論是模型大小和訓練 tokens 要一起平衡，不能只加參數。

解法：

每次 grow 都必須配套新 tokens / high-quality curriculum

也就是：

grow parameters
grow data
grow difficulty

不能只 grow architecture。

難點二：function-preserving 不等於 capability-increasing

Net2Net / morphism 只能讓你「長大時不壞掉」，不保證「長大後變強」。

解法是把 grow 拆成兩步：

1. preserve old function
2. train new capacity on harder distribution

你要設計 post-growth curriculum：

old replay 30%
new domain 30%
hard reasoning 20%
teacher-generated challenge 10%
adversarial / conflict data 10%
難點三：外部記憶很容易變成作弊

如果推理時還依賴 memory，那不是單一模型長大。

解法：

memory only during training
must pass no-memory eval

每個結果都要報兩個數字：

with scaffold
without scaffold

最後論文只主張 without scaffold。

何時 prune
